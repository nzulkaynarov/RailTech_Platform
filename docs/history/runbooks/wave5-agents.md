Источник задач — `docs/audits/2026-10-18-main-e0f089e.md` (строки FIX-50…54 и «Реестр находок»), статусы — `docs/PROGRESS.md`,

## 2. Рабочее место

Worktree — только `.claude/worktrees/<задача>` от свежего `origin/main` (ORCHESTRATOR §4.1); ветки: FIX-50
`qa/erp-50-m1-gate-run`, FIX-51 `qa/cabinet-51-m2-gate-run`, FIX-52 `docs/orch-52-docs-truth`, FIX-53 `docs/orch-53-process-rules`,

**Стенд один на всех.** QA-исполнители работают с ним только через браузер и публичные API; `make up`/`make down` делает лид,
между раундами (после слияния кода — пересборка от свежего `main`: `git -C <корень> pull --ff-only`, `make up`, `make smoke`).
Без `make down -v` и без правки `.env`. Данные: FIX-50 и FIX-51 работают каждый **со своей компанией-клиентом** (имена с префиксом
задачи), чужие сделки не трогают.

(FIX-35), считается набором.

## 6. Цикл лида

1. Раунд: стенд (§2) → worktree и зависимости → исполнители с «§5.0 + §5.x» → фоновый монитор → ждать докладов.
2. Ревью свежим субагентом (read-only): «готово, когда»; QA — скриншоты открываются и без токенов/ПДн, axe приложен, дефекты
   воспроизводимы по шагам; код — тест-first, нет правок вне зон §3, `make ci-local` в теле PR, PROGRESS не тронут.
   Блокеры — исполнителю одной строкой; иначе — `gh pr merge --auto --merge <n>`.
3. CI не опрашивать; одна проверка своих PR перед раундом. Красный «CI ok» или конфликт — исполнителю чинить локально.
4. Исполнитель молчит > 20 мин — смотреть его worktree и доводить самому; зависшие субагенты — останавливать (TaskStop).
5. Убирать worktree влитых задач и тестовые контейнеры своих `ERP_TEST_NS`.

## 7. Если что-то идёт не так

- Стенд не поднимается / `make smoke` красный → лид: `docs/runbooks/stand.md` «Если не поднимается»; `.env` — к владельцу.
- Роль или вход не получить штатно → это дефект прогона (P1), не обход через `createsuperuser`/shell.
- Нужен токен из письма → логи `erp-backend`; токен только в браузер; утёк в артефакт — удалить коммит до push, сообщить лиду.
- Дефект требует правки контракта → QUESTIONS, архитектору; в волне — то, что можно по контракту.
- Код 137 у контейнеров → бюджет Docker §2.
