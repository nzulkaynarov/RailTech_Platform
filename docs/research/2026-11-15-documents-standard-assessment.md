# Стандарт документов и писем: разбор рекомендаций

Дата: 2026-11-15 · автор — архитектор · итог — [стандарт документов](../architecture/documents-standard.md), план §3c

Владелец передал документ «Единый стандарт корпоративных документов и коммуникаций» (швейцарский стиль, Inter и
JetBrains Mono, шкала slate, четыре вида документов, HTML-письмо, подпись сотрудника, базовый шаблон Jinja2 для
WeasyPrint) с поручением изучить, провести своё исследование и показать, что берём.

## 1. Что уже есть

Сверено с `packages/rt-docs` (`css.py`, `html.py`, `commercial.py`) и шаблонами почты ERP (`templates/emails/`).

| Рекомендация | У нас |
|---|---|
| Таблицы без вертикальных линий, 0,5 pt | `table.rt-grid`: линии 0,5 pt только по горизонтали |
| Повтор шапки таблицы, строка не рвётся | `thead { display: table-header-group }`, `tr { break-inside: avoid }` |
| Числа вправо, `tabular-nums` | `html { font-variant-numeric: tabular-nums }`, `.rt-num` |
| Сумма прописью | `amount_in_words` ru, uz, en |
| Подпись не отрывается | `table.rt-signature { break-before: avoid; break-inside: avoid }` |
| QR проверки 22 мм | `.rt-verify-qr` 22 мм (ADR-0024 п. 5) |
| «Стр. N из M», номер со 2-й страницы | `@bottom-right` со счётчиками, `string-set: rtdocref` |
| Шаблон без исходника, цвет из бланка | ADR-0020: тело JSON, цвет и шрифт — только из бланка |
| Рендер без сети, шрифты вшиты | безопасный fetcher, изолированный fontconfig |

## 2. Что не так сейчас

- Шрифт документов — Noto Sans, экран — Inter: разные буквы в PDF и в кабинете.
- Палитра пакета своя (`#20242b`, `#5a6270`, `#7a828f`, `#8a909b`), не из токенов; подвал `#8a909b` светлее нормы печати.
- Шапка таблицы — цветом акцента с линией 1,2 pt, без подложки; итоги — только жирным.
- Номер и реквизиты письма — строками слева и справа, без плашки; тема письма — обычным заголовком.
- Почта ERP: цветная полоса на всю ширину с названием, тень, кнопка цветом акцента, синие ссылки — другой стиль, чем
  экран и PDF.
- Подпись сотрудника — свободный текст в профиле CRM, без шаблона.
- Артикула и срока поставки в таблице позиций нет.

## 3. Своё исследование

- **Узбекский стандарт оформления.** O'z DSt 1157:2008 «Требования к оформлению документов» — карточка на lex.uz есть,
  текста в открытом доступе найти не удалось. До сверки опираемся на ГОСТ Р 7.0.97-2016, по которому уже стоят поля
  20 / 15 / 20 / 20 мм; сверка полей и мест реквизитов по тексту O'z DSt — до D-2.
- **Язык делопроизводства.** Закон «О государственном языке» (ст. 10): делопроизводство — на государственном языке, в
  коллективах, где большинство не владеет узбекским, — наряду с ним и на других. Документы на трёх языках у нас уже есть
  (ru, uz-латиница, en); двуязычный договор — обычная практика с иностранными поставщиками, норма о нём для договоров
  между организациями не найдена — остаётся выбором шаблона.
- **Выравнивание.** Исследования не дают однозначного ответа для печати: левое выравнивание быстрее читается с экрана и
  удобнее людям с дислексией, по ширине на бумаге выглядит строже и читается не хуже при переносах. Решение: влево по
  умолчанию, по ширине — выбор автора абзаца (уже есть в теле).
- **Почта.** Outlook для Windows (2016–2021, классический 365) рисует письмо движком Word: нет flex и сетки, нет своих
  шрифтов, скругления не работают; надёжно — таблица 600 px и стили в атрибутах. Кнопка — ячейка таблицы с отступами;
  в Outlook углы прямые, это допустимо.
- **Шрифты.** Inter (OFL) покрывает кириллицу с расширениями (`ўқғҳ` — U+045E, U+049B, U+0493, U+04B3) и латинский
  `ʻ` (U+02BB) — проверено по таблице диапазонов `@fontsource-variable/inter`; JetBrains Mono (OFL) — проверка в D-1
  тестом рендера, как сейчас у Noto.
- **Ч/б печать.** Тёмная плашка с белым текстом на лазерном принтере и копире идёт полосой, мелкий белый текст
  заливается. Подложка `#F8FAFC` и линии не мешают: текст остаётся на светлом.
- **Факсимиле.** Картинка подписи и печати в PDF юридической силы не добавляет (сила — у подписи на бумаге или ЭП) и
  упрощает подделку; у нас есть отметка ЭП и код проверки.

## 4. Решение

| Рекомендация | Итог | Почему |
|---|---|---|
| Inter и JetBrains Mono в документах | **принято** | одна ДНК с экраном; Noto Serif остаётся для бланка «с засечками» |
| Палитра slate из токенов | **принято** | токены `print` в `ui-tokens`, литералов нет |
| Шапка таблицы — подложка, 7,5 pt прописными `#475569` | **принято** | как в реестрах экрана |
| Коды моноширинным | **принято** | номер, код проверки, ИНН, МФО, счёт, артикул |
| Шапка бланка: логотип и название слева, реквизиты справа | **принято** | номер и дата КП — в строку заголовка |
| Линия под шапкой 1,5 pt | **принято** | цветом акцента бланка (по умолчанию графит) |
| Паспорт письма плашкой в две колонки | **принято** | |
| Тема письма с чертой слева | **принято** | |
| Подпись, отметка, QR одной строкой | **принято** | без картинки факсимиле |
| Полоса условий КП | **принято** | и для счёта (срок оплаты) |
| Артикул и вторая строка с характеристиками | **принято** | срок поставки — колонкой, если задан |
| Блок итогов справа 75 мм | **принято с изменением** | «К оплате» — жирным на светлой подложке с линией акцента, не белым на графите |
| Сумма прописью под итогами | **принято** | уже есть, стиль — `#475569` |
| Примечания нумерованным списком | **принято** | |
| HTML-письмо 600 px, карточка с рамкой, сводка, одна кнопка | **принято** | без цветной полосы и тени; углы в Outlook прямые |
| Единая подпись сотрудника | **принято** | собирается из профиля и настроек компании |
| Пункты договора с выступающей нумерацией | **принято** | |
| Переменные договора полужирным | **принято** | значения полей, не произвольный текст |
| Двуязычный договор 50/50 | **отложено** (D-6) | нужны парные пункты в шаблонах |
| Поля 15 / 15 / 18 / 18 мм | **не принято** | ГОСТ Р 7.0.97, левое 20 мм под подшивку |
| Кегль письма 10–10,5 pt | **не принято** | письма читают с бумаги в канцеляриях — 11 pt; КП — 9,5 pt |
| Запрет выравнивания по ширине | **не принято** | влево по умолчанию, выбор автора остаётся |
| Тёмная плашка «Итого» | **не принято** | противоречит правилу ч/б печати того же документа |
| Колонтитул `#94A3B8` | **не принято** | на бумаге пропадает; `#475569` |
| «Документ сформирован в системе…» | **не принято** | реклама системы в официальном документе; место «Исполнителя» |
| «Конфиденциально» на каждом документе | **изменено** | флажок шаблона |
| Факсимиле и печать картинкой | **не принято** | см. §3 |
| НДС и сумма с НДС в каждой строке | **не принято** | девять колонок не помещаются; НДС в итогах, ставка из настроек |
| Шаблон Jinja2 с `@import` шрифтов из сети | **не принято** | рендер без сети; из шаблона взяты значения стилей |
| Второй акцент `#1D4ED8` в документах | **не принято** | акцент задаёт бланк компании |

## 5. Порядок

D-0 (этот документ, стандарт, план) — сейчас; D-1…D-6 — серверная работа, по правилу «фронт до 1 декабря» идёт в
декабре (план §3c). D-1 меняет вид всех документов на rt_docs сразу, поэтому первым.
