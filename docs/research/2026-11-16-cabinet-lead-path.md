# Путь лида в Кабинете: разбор и макеты (ЛИД-0)

Дата: 2026-11-16. Решение владельца и шаги — [план §3d](../runbooks/plan-2026-11-12.md). Макеты — артефакт «Путь лида в
Кабинете» (пять экранов: две посадочные, вход, «код отправлен / нет доступа», меню).

## Что сейчас

- `/login` показывает всё сразу: почта, «войти по коду», Telegram, «Я новый клиент», «Стать партнёром», демо-вход
  (только на локальном стенде). Никому не объясняет, зачем ему кабинет.
- `POST /api/portal/v1/auth/magic-link` уже отвечает одинаково на любой адрес (решение 2026-11-08, FX-3): по ответу
  нельзя узнать, есть ли адрес в базе. Экран «нет доступа» — чистый фронт.
- Партнёру положены «Мои товары», «Каталог и заявки», «Сообщения», «Профиль» (`apps/erp/backend/portal/services/roles.py`);
  «Компании», «Команды» и документов у него нет — ЛИД-6.

## Как делают другие

| Кто | Что берём | Что не берём |
|---|---|---|
| Faire (оптовый маркетплейс) | Две аудитории, две дорожки: «покупателям» и «брендам», у каждой своя форма и своя страница «как это работает»; общий призыв «Sign up to shop, or apply to sell» | Раздельные аккаунты для двух ролей: у нас одна компания может быть и клиентом, и партнёром — роли складываются |
| Coupa Supplier Portal | Поставщику прямо сказано, что подключение бесплатное; регистрация без приглашения — короткая форма, остальное — после | Длинная анкета юрлица и платёжных данных до входа |
| SAP Business Network (бывш. Ariba) | Вход по приглашению со ссылкой и сроком — у нас так уже устроено (ссылка и код в письме) | Отдельная регистрация на чужой площадке |
| Ahrefs, Mixpanel (песочницы) | Демо без регистрации на заранее заполненных данных; из демо — призыв к действию | — |
| Интерактивные туры (Supademo, Walnut, Chameleon) | Короткий путь, построенный вокруг задачи покупателя, а не списка функций | Сторонний конструктор туров: настоящий кабинет на демо-данных убеждает сильнее и не устаревает |
| Беспарольный вход в B2B-порталах | Код на почту живёт 5–15 минут, повторная отправка — с ограничением и видимым таймером; ссылка в письме — вторым способом | Пароль как запасной путь: не нужен, Telegram уже есть |
| OWASP (перечисление аккаунтов) | Одинаковый ответ на любой адрес: «если адрес приглашён, код уже в письме» | Сообщение «пользователь не найден» |

## Решения для макетов

1. **Посадочные** «Клиентам» и «Партнёрам» — одна механика, разное обещание. Первый экран: заголовок, три выгоды,
   форма из двух полей (почта и компания), демо — второй кнопкой, «Уже работаете с нами? Войти». Ниже — снимок кабинета
   и «Как это работает» в четыре шага. Без придуманных цифр: срок ответа — [СРОК], пока его не назовёт владелец.
2. **Вход** — только почта → код и Telegram; справа — спокойная панель с одной фразой и снимком. Внизу одна строка
   «Ещё нет доступа? Клиентам · Партнёрам».
3. **«Код отправлен»** — одинаковый текст для любого адреса, шесть ячеек кода, таймер повторной отправки. Ниже —
   «Письма нет и приглашения не было?» с двумя кнопками на посадочные; почта переносится в форму.
4. **Меню** — блоки «Покупаю · Продаю · Документы · Компания» для любой роли (сделано в ЛИД-1). Телефон: четыре главных
   раздела роли и «Ещё».

## Открыто для владельца

- Срок ответа менеджера на посадочной ([СРОК]) и есть ли что сказать о количестве товаров или партнёров — только
  настоящие цифры.
- Демо (ЛИД-7): настоящий кабинет на демо-компании, только чтение — рекомендуем вместо картинок.
