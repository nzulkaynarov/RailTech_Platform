# Дополнения к инвентаризации зашитых правил

Один файл на PR: `additions/<задача>.md` (имя — как у worktree задачи, например `sc8-status.md`). Так открытые PR не
правят одно место [инвентаризации](../inventory.md) и не конфликтуют.

Что писать — те же колонки, что в таблицах инвентаризации:

| Процесс | Что зашито | Где | Частота | Форма настройки | Кто менял бы |
|---|---|---|---|---|---|

Только структура и права: без значений компании, имён людей и контрагентов. Перед засевом фазы 1
([ADR-0031](../../../adr/0031-processes-as-data.md)) дополнения сводятся в основной файл и этот каталог очищается.
