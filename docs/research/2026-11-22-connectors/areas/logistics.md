# Логистика: коннекторы и интеграции (ж/д, контейнеры, курьеры, автоперевозки, TIR, штрихкоды, карты)

Срез на 2026-11-22. Опирается на прошлый обзор `docs/research/2026-10-23-architecture/arch-research-uz-integrations.md` §7, §9 (origin/main) и обновляет его.

**Чем ERP уже закрывает логистику (сверено с origin/main):**
- Отгрузка клиенту (`Fulfillment`): поля `tracking_number`, `carrier`, `waybill`, вложение-подтверждение, статусы PENDING…ACCEPTED. Файлы: `apps/erp/backend/crm/serializers/projects.py`, `apps/erp/backend/crm/constants.py`.
- Уведомление поставщика об отгрузке (ASN, `SupplierOrderShipmentNotice`) тоже хранит `carrier` и `tracking_number`: `apps/erp/backend/supply/models.py`.
- Есть справочник Incoterms 2020, ТН ВЭД, приёмка с серийными номерами и партиями (`inventory/services/trace.py`), `qrcode` и WeasyPrint.

**Чего нет:** никакой внешней логистической интеграции. Все статусы ставятся вручную.

## 0. Что важно знать до выбора

1. **Закон о ПДн изменился, исходное правило «ПДн граждан РУз — только в РУз» устарело.**
   - Закон ЎРҚ-1125 от 26.03.2026, в силе с 27.03.2026, полностью переписал ст. 27¹ ([lex.uz/docs/8099215](https://lex.uz/docs/8099215)).
   - Обязательно хранить в РУз теперь только биометрические и генетические данные и данные абонентов операторов связи.
   - Остальные ПДн можно хранить за рубежом при одном из трёх условий: страна признана «адекватной»; стандартные договорные условия или корпоративные правила; утверждённые международные стандарты ([kun.uz 27.03.2026](https://kun.uz/en/news/2026/03/27/uzbekistan-amends-personal-data-law-to-facilitate-global-payment-systems)).
   - Список из 49 «адекватных» стран утверждён постановлением Кабмина 29.07.2026. В нём есть США, Великобритания, Россия, Германия. Казахстан и Китай в заметке не названы. Об утечке надо сообщить в течение 24 ч ([kun.uz 04.08.2026](https://kun.uz/en/news/2026/08/04/uzbekistan-approves-49-countries-for-simplified-personal-data-transfers)).
   - **Это стоит подтвердить у юриста.** Для логистики почти все данные не персональные: трек-номера, номера контейнеров и вагонов, адреса компаний. ПДн появляются только в курьерских заявках (ФИО и телефон получателя).
2. **Санкции.**
   - РЖД в США: Non-SDN, Directive 3 по EO 14024, то есть запрет только на новый долг и капитал ([OFAC](https://sanctionssearch.ofac.treas.gov/Details.aspx?id=34736)).
   - РЖД в Великобритании: заморозка активов с 24.03.2022 ([gov.uk](https://gov.uk/government/news/foreign-secretary-announces-65-new-russian-sanctions-to-cut-off-vital-industries-fuelling-putins-war-machine), [Kelley Drye](https://www.kelleydrye.com/viewpoints/blogs/trade-and-manufacturing-monitor/additional-u-k-sanctions-targeting-russian-industries-banks-elites-belarusian-entities.md)).
   - РЖД в ЕС: в санкционных списках по [index1520](https://index1520.com/en/news/rossiyskie-zheleznye-dorogi-v-sanktsionnom-spiske-es-i-ssha/), точное приложение не подтверждено.
   - Основной владелец 2ГИС — Сбербанк, который под санкциями США ([spot.uz](https://www.spot.uz/ru/2023/05/20/2gis-gone/)).
   - Яндекс: в найденных источниках в списках США и ЕС не значится, есть только санкции Украины ([НАЗК](https://nazk.gov.ua/en/nacp-adds-yandex-services-to-the-list-of-candidates-for-sanctions)). Перед договором проверить по OFAC.
   - Западные сервисы (DHL, Maersk, Shipsgo, TrackingMore, 17TRACK, Google) клиентам из РУз не закрыты.
3. **Ограничение исследования.** Лимит веб-поиска сессии исчерпан. Не проверены: China Railway 95306, цены project44 и Vizion, прямые API «Почты Узбекистана» и СДЭК-УЗ, прейскурант «Поиска вагонов» Альта-Софт, Yuk.uz.

## 2. Больше пользы за меньше работы

1. **Отчёты экспедиторов и поставщиков → статусы и сроки** (п. 1). Новых вендоров нет: почта, Docling и модель уже на проде. Закрывает основной поток B2B-логистики, где статус приходит письмом или Excel. S–M.
2. **Словарь событий отправки (DCSA + GS1 CTE) и ручной адаптер «отправка»** (п. 2, п. 14): вагон, контейнер, CMR, ЭТТН, станции, ГНГ из ТН ВЭД. После этого любой будущий трекер подключается без смены модели. S.
3. **Автотрекинг посылок по уже собранным трек-номерам** (п. 3 или 3a). Для DHL можно бесплатно напрямую, для смеси перевозчиков — агрегатор от ~$11–74 в месяц. Срок прибытия сам попадает в сделку и Кабинет. S–M.
4. **Этикетки и сканирование готовыми MIT-библиотеками** (п. 22), вместе с MVP-T1 (серии и партии уже есть). S–M.
5. **По условию, после ответа владельца:**
   - Shipsgo — если контейнеры фрахтуем сами;
   - «Поиск вагонов» или «ЖД-Тариф» Альта-Софт — если свои ж/д отправки;
   - BTS Express API — если курьерских отгрузок по РУз много;
   - свой OSM — если нужен расчёт автодоставки по км.

**Не тратить время:** ЭТРАН и РЖД, ATI.SU, 2ГИС, платные Яндекс Карты, членство GS1 и Verified by GS1, TIR/eTIR/e-CMR, прямой API Maersk, биржи Yuk.uz и Cargoinfo.
