# Госсервисы Узбекистана и комплаенс: что подключать (исследование 2026-11-22)

Сверено с исследованиями `docs/research/2026-10-21-business-audit/research-uz-edo.md` и `docs/research/2026-10-23-architecture/arch-research-uz-integrations.md` в ветке origin/main. Из них взято только то, что подтвердилось заново или изменилось. Метки: **[Ф]** — факт со ссылкой, **[П]** — мой вывод, его нужно проверить.

**Ограничение.** Общий лимит веб-поиска сессии (200 запросов) закончился посреди работы. Не проверены: перечень маркируемых товаров Asl Belgisi на 2026 год, текущее состояние API Faktura (api.faktura.uz 22.11.2026 отказал в соединении) и E-DOCS (страница Postman отдаёт только заголовок), тарифы агрегаторов тендеров, участие Google LLC в DPF.

## 0. Главное

1. **Самая большая польза за меньшую работу — госзакупки как канал продаж, а не интеграция.**
   - АО «Ўзбекистон темир йўллари» за январь–март 2026 года заключило 1 069 договоров на 1,66 трлн сум [Ф, PDF railway.uz](https://railway.uz/upload/iblock/7e2/mt2gmkxlksbgjtn6v3sujkzzweg7laiw.pdf).
   - Из них 550 через электронный магазин, 103 через национальный магазин, 33 через аукцион, 34 запроса предложений на 1,1 трлн сум, 177 через кооперационный портал.
   - API у площадок не найдено. Работает связка без кода: регистрация поставщиком на xarid.uzex.uz, затем почтовые уведомления агрегатора в уже работающий IMAP-ящик, оттуда лид в CRM.
2. **Закон о персональных данных изменился. Исходная посылка «ПДн граждан РУз хранить только в РУз» устарела.**
   - ЗРУ-1125 от 26.03.2026 действует с 27.03.2026. Обязательное хранение в стране теперь только для биометрических и генетических данных и данных абонентов телеком-операторов. Регистрация в Госреестре баз ПДн нужна только таким базам ([lex.uz ЗРУ-547 ст. 20, 27¹](https://lex.uz/ru/docs/4396428), [kun.uz](https://kun.uz/ru/news/2026/03/28/xraneniye-nekotoryx-personalnyx-dannyx-za-predelami-uzbekistana-razresheno)).
   - ПКМ № 415 от 29.07.2026 действует с 03.08.2026. Он утвердил 49 стран, куда ПДн передаются без разрешений и уведомлений ([lex.uz](https://lex.uz/ru/docs/8369688), [spot.uz](https://www.spot.uz/ru/2026/08/04/personal-data-abroad/)). Подробно — §2.
3. **Налоговый ЭДО: новых публичных API нет.** Документация Didox по-прежнему за логином; 22.11.2026 страница отдаёт только «03. Логин | API Документация» ([api-docs.didox.uz](https://api-docs.didox.uz/)). Ускорить шаг 8 можно только организационно: запросить у Didox партнёрский токен и тестовый контур заранее.
4. **Трансграничный ЭДО с Россией уже работает через роуминг НИЦ «Янги технологиялар».** Документы российских поставщиков из Saby и Контура доходят до любого оператора в Узбекистане, то есть до нашего Didox. Нам ничего писать не нужно ([comnews 28.08.2025](https://www.comnews.ru/content/240932/2025-08-28/2025-w35/1018/rossiya-i-uzbekistan-realizovali-transgranichnyy-edo-elektronnoy-podpisyu), [saby.ru](https://saby.ru/edo/tedo/legal)).
5. **ЕГРПО для программы закрыт.** Проверено 22.11.2026: `module.stat.uz/egrpo/ru/` перенаправляет на вход OneID (`id.egov.uz?client_id=e-stat`). OneID для коммерческих организаций платный по договору ([egov.uz](https://egov.uz/en/projects/one-id)). Проверка контрагента остаётся набором ссылок на официальные реестры плюс один открытый Excel-файл (§1, строки B2–B3).

## 2. Персональные данные: что изменилось и что это значит

- **[Ф] Хранение.** Ст. 27¹ ЗРУ-547 в редакции ЗРУ-1125 действует с 27.03.2026. Хранить в РУз обязательно только биометрические и генетические данные и данные абонентов телеком-операторов. Остальные ПДн можно хранить и обрабатывать за рубежом при выполнении одного из условий: страна в перечне Кабмина; стандартные договорные условия или корпоративные правила, утверждённые уполномоченным органом; международные стандарты из утверждённого перечня. По ст. 20 регистрация в Госреестре баз ПДн нужна только базам с обязательной локализацией ([lex.uz](https://lex.uz/ru/docs/4396428)).
- **[Ф] Перечень стран (ПКМ № 415, действует с 03.08.2026).** 49 стран, передача без разрешений и уведомлений.
  - В перечне: Россия, все страны ЕС (в том числе Германия, Финляндия, Нидерланды), Великобритания, Южная Корея, Япония.
  - США — только для компаний, участвующих в EU-US Data Privacy Framework.
  - Нет в перечне: материковый Китай, ОАЭ, Казахстан, Турция ([lex.uz](https://lex.uz/ru/docs/8369688)).
- **[П] Выводы, подтвердить юристу:**
  - Прод PRO DATA в Ташкенте соответствует закону с запасом.
  - Копия бэкапов на Яндекс Диске — передача в страну из перечня. Это может закрыть пункт OWNER-CHECKLIST «фраза юриста о Яндекс Диске».
  - Google Drive (США): проверить участие Google LLC в DPF.
  - Anthropic в политике конфиденциальности ссылается на стандартные договорные условия, об участии в DPF не пишет ([anthropic.com/legal/privacy](https://www.anthropic.com/legal/privacy)). Маскирование ПДн перед моделью (DECISIONS 2026-11-11) оставить.
  - Китайские сервисы поставщиков и юрисдикции не из перечня — передавать ПДн граждан РУз только с согласия субъекта (ст. 15) или после утверждения стандартных договорных условий. Их утверждения я не нашёл.
  - Биометрию не собирать: иначе потребуются локализация и регистрация базы.
