# ADR ансамбля — индекс
Статус: действует · Владелец: архитектор · Обновлено: 2026-10-29

Архитектурные решения всего ансамбля, формат MADR: «Контекст → Варианты → Решение → Последствия», статус в шапке файла
(`proposed` → `accepted` → `superseded`). Решения только внутри CRM — отдельная серия [`crm/`](crm/README.md) с
обозначением «ADR CRM-NNNN» (номера пересекаются). Отклонение от действующего ADR — только новым ADR и решением владельца
(ORCHESTRATOR §3 п. 10); как написать — скилл `adr` (`.claude/skills/adr/`).

Колонка «Что изменило позже» — где читать поправки; сам ADR при расхождении уступает тому, что указано в ней.
