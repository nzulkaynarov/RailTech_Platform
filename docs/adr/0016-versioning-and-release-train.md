# 0016. Версии и релизный поезд

- Статус: accepted (владелец, 2026-10-23) · Дата: 2026-10-23 · Основание: стратегия §3.6, §7

## Решение
1. Версия платформы `ГГГГ.ММ` для всего ансамбля, ежемесячный поезд, исправления — `ГГГГ.ММ.N`; тег git и примечания к выпуску.
   До 1.0 этапы стратегии нумеруются 0.9 → 0.12 внутри поезда.
2. Контракты (`packages/contracts`): semver у каждого файла; в мажоре только добавления; ломающее — новый мажор в пути (`/v2`)
   и в типе события (`.v2`), двойная публикация на переходе; старый мажор ≥ 6 месяцев и ≥ 2 поезда; `Deprecation`/`Sunset`,
   после снятия — 410. Проверка в CI: `oasdiff` для OpenAPI и сравнение схем событий.
3. Миграции БД: до 1.0 данные прода можно сбрасывать (стратегия §7); с 1.0 — только «расширить → перенести → сузить».
4. Флаги функций — на компанию и на коннектор.
5. LTS — с появлением внешних компаний (этап G).
