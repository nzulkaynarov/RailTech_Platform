# 0018. Темы и семантические токены

- Статус: accepted (владелец, 2026-10-22 замечание, 2026-10-23 стратегия) · Дата: 2026-10-23 · Основание: стратегия §3.5
- Отложено (DECISIONS 2026-10-29): этап C4 «Темы» — после 1.0; тема «Как в ERP» не делается (фронтенд ERP отключается).

## Решение
1. `packages/ui-tokens` v1.0: семантические токены (поверхность, приподнятая поверхность, текст основной/вторичный/третичный,
   рамка, разделитель, акцент, акцент при наведении, статусы успех/внимание/ошибка/инфо и их фон) поверх палитры.
2. Темы — наборы значений: «Светлая» (текущая), «Тёмная», «Как в ERP» (палитра shadcn ERP); переключатель в профиле
   сотрудника и умолчание компании в Admin.
3. В коде компонентов Платформы и Cabinet — только токены; «зашитых» цветов нет (проверка линтером).
4. Контраст ≥ 4.5:1 проверяется для каждой темы.
