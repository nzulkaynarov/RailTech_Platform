# 0005. ИИ во всех системах через общий шлюз LiteLLM, трейсы в Langfuse, принципы CRM

- Статус: proposed · Дата: 2026-10-13

## Контекст
CRM: LiteLLM по алиасам, бюджеты, Langfuse, evals, MCP с HMAC-контекстом. B2B: прямой SDK провайдера
из Celery, без трейсов и evals.

## Решение
Один LiteLLM и один Langfuse в `infra/ai`; оба бэкенда зовут модели по алиасам; ключи и бюджеты — в
консоли админа CRM; ERP получает `LITELLM_URL` и ключ как секреты. Принципы CRM обязательны в ERP: код
решает, модель предлагает; идентификаторы компании только из подписанного контекста; промпты в файлах
с версией по хэшу; evals с golden-кейсами; платные прогоны по согласию. Cabinet своего ИИ не имеет —
вопросы клиента обслуживает агент CRM.

## Варианты
1. Два независимых ИИ-стека — двойные ключи, бюджеты, без единых трейсов. Отклонено.
2. Общий шлюз — выбрано.

## Последствия
Перевод задач ERP на шлюз (M1-ERP-06), evals-каркас в ERP, единая страница расходов.
