# 0003. Сотрудники: CRM — источник истины по людям и доступам; переход между системами по SSO-токену

- Статус: accepted (владелец, 2026-10-13) · Дата: 2026-10-13

## Контекст
Сотрудник может работать и в CRM, и в ERP; владелец требует переключение без повторного входа и
ролевую политику. Обе системы уже используют JWT HS256.

## Решение
Пользователей и `platform_access` ведёт CRM (инвариант «≥ 1 активный администратор» там же). При выдаче
доступа CRM провижинит пользователя в ERP. Переход — одноразовый подписанный токен на 60 с (общий
секрет), принимающая сторона выдаёт свою сессию. Отзыв доступа в CRM отзывает сессии ERP. Роли: CRM
admin = суперпользователь ERP; manager → роль бэк-офиса по карте. Клиенты входят только в Cabinet
(Telegram initData / magic-link).

## Варианты
1. Keycloak сейчас — лишний сервис на старте; остаётся путём миграции (ADR-0005 CRM).
2. Общий JWT-секрет и прямое доверие токенам — смешивает сессии и аудит двух систем. Отклонено.
3. Токен-передача — выбрано.

## Последствия
~150 строк на сторону, аудит переходов, тесты матрицы ролей и одноразовости токена.
