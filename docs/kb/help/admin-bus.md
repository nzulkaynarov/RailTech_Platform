«Настройки · Журнал · История», вид «Обмен между системами» — как части платформы передают друг другу события: доставки, входящие и подписчики. Сбойную доставку можно отправить ещё раз. Страница только для администратора с полным доступом; действия людей — переключатель «Действия людей» над списком.
