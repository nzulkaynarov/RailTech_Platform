«Настройки → Первый запуск» виден, пока не сделаны все шаги. Любой шаг можно сделать позже.

1. **Администратор** — уже вы.
2. **ERP** — «Подключить ERP»; на новой установке код не нужен.
3. **Ваша компания** — от её имени оформляются документы.
4. **Банковские реквизиты для счетов** — без расчётного счёта и МФО счёт клиенту не выставить. Шаг ведёт в «Компания и бланки», вкладку «Реквизиты»; пока их нет, баннер напоминает.
5. **Адрес кабинета клиента** — подробно в статье «Подключения».
6. **Остальные подключения** — бот, почта, модели ИИ и первый сотрудник; форма каждого открывается справа.
