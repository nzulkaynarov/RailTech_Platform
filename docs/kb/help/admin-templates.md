«Настройки · Компания · Шаблоны документов» — вкладки:

- **Документы** — шаблоны КП, договора, счёта и акта. Образец платформы можно открыть и скопировать к себе; свой шаблон — править с образцом.
- **Письма** — шаблоны писем клиентам. Включённый шаблон сразу заменяет стандартный для всех получателей.
- **Условия КП** — значения по умолчанию для новых КП: валюта, базис, НДС, наценка, сроки. Здесь же переключатель **«Напоминать клиентам о просроченных счетах»** (по умолчанию выключен): если включить, раз в сутки в 10:00 по Ташкенту по каждому счёту, у которого срок оплаты прошёл больше трёх дней назад, клиенту уходит одно напоминание — в колокольчике кабинета и письмом контакту проекта и приглашённым в кабинет. Пока переключатель выключен, клиенты напоминаний не получают; после включения напоминание по уже просроченным счетам уйдёт в ближайшие 10:00.
