Модуль «Чаты» соберёт в одном месте рабочую переписку команды по проекту и переписку с клиентами.

## Где это сейчас
Экран чатов появится к пилоту. До тех пор:
- переписка с клиентами — в «Клиенты → Ждут ответа» (там же «Взять в работу» и ответ клиенту);
- обсуждения внутри команды пока идут в мессенджерах вне системы.

Чат проекта будет создаваться вместе с заявкой, и события проекта (резолюция, КП, счёт) будут писаться в него сами.
