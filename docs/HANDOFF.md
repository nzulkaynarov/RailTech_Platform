## 1. Где мы (2026-10-23)

- Монорепозиторий `RailTech_Platform` (GitHub `nzulkaynarov/RailTech_Platform`, временно публичный — до продуктива вернуть в
  приват); `main` защищена, только PR с зелёным «CI ok», автослияние после ревью лида.
- **Стратегия утверждена владельцем с карт-бланшем** (ADR-0013…0019): ядро CRM / EDS / ERP за шиной `rt_bus`, коннекторы
  снаружи, версии `ГГГГ.ММ`; старые фронты CRM и ERP удаляются на C2 без сосуществования; прод — на чистых базах.
- **Что есть в коде.** CRM (`apps/crm`): лиды, клиенты, бот с сервисным режимом через `erp-mcp`, база знаний, консоль
  администратора (подключения, модели ИИ, почта, внешние сервисы, расходы), вход и роли Платформы. ERP (`apps/erp`): каталог в
  два слоя, КП, договор, счёт, акт, портальный и интеграционный API, вебхуки в CRM, `erp-mcp`. Cabinet (`apps/cabinet`): веб и
  Mini App над портальным API. Платформа (`apps/platform`): P0 и P1 закрыты, гейт P1 принят — вход через CRM, сессия BFF,
  каркас, Dashboard, уведомления, поиск, Admin · Оргструктура (`runbooks/plt_p1_gate_report.md`).
- **Прод:** VPS1/VPS2 подготовлены (`runbooks/servers.md`), прод-compose и деплой готовы; Платформа на проде не развёрнута —
  нужны A-запись `platform.railtech.uz`, `PLATFORM_DOMAIN` и деплой от владельца (`OWNER-CHECKLIST.md`).
- **Документация** с 2026-10-23 — только в `docs/` (ORCHESTRATOR §3 п. 17, DOCS-1).

## 3. Рабочее место владельца (что важно знать агенту)

- Правила среды, тестов и CI — раздел «Среда разработки, тесты и CI» `CLAUDE.md` корня; worktree — только `.claude/worktrees/<задача>`,
  зависимости в новом worktree ставит тот, кто его готовит (`make -C apps/<app> install`).
- Docker Desktop ≈ 12 ГБ памяти, подсеть VM закреплена `VpnkitCIDR: 192.168.65.0/24`; стенд `make up` (≈ 4,5 ГБ) на порту
  `HTTP_PORT=8088`; рядом помещаются не больше двух наборов тестов ERP (`ERP_TEST_NS=<задача>`, контейнеры `rt-erp-test-*`).
- После `git pull` с правкой `infra/caddy/Caddyfile.dev` — `make caddy-reload`.
- Облачная сессия без машины владельца: образы — из `mirror.gcr.io`; тесты ERP — в venv хоста против контейнеров
  `pgvector/pgvector:0.8.7-pg17` и `redis:7.4.11`; перед push — `gitleaks git --config .gitleaks.toml .`.
