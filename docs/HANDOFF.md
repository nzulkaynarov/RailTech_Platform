## 2. Что сделано по системам

**CRM (`apps/crm`)** — рабочая система из `crm-rt-ai` плюс:
- ADR-0022: «Передан в бэк-офис» = стадия `customer`, режим `local`/`erp` по факту настройки коннектора ERP;
- коннектор «ERP» в «Подключениях» с «Проверить связь» и строкой на «Состоянии системы» (адрес в настройках, Q-11);
- источники лидов `web` / `phone` / `email` / `referral`, публичная форма `POST /api/v1/leads/web` с антиспамом и
  обязательным согласием `consent`, ручное создание «Новый лид», склейка с Telegram по номеру;
- коннектор «Почта» (SMTP) и журнал писем, приглашение сотрудника и сброс пароля по почте (ADR-0023);
- страница «Расходы»: дашборд затрат на ИИ по ансамблю из журнала LiteLLM, теги `system/feature/model` на всех вызовах;
- центр внешних сервисов (ADR-0024): реестр, фоновые проверки, метрики, выключатели, инциденты, оповещения.
- Миграции Alembic: голова — `0022_external_services`.

**ERP (`apps/erp`)** — выделенная из B2B система (M1-ERP-01..10, M2-ERP-01..03):
- Удалены операторская плоскость, лиды, чат, KYC, подписки/entitlements, маршрутизация между продавцами, ЖД-домен.
- Новые канонические приложения (`accounts`, `parties`, `catalog`, `sales`, `finance`, `documents`, `ai`, `core`, `portal`).
- 6 ролей бэк-офиса (`CALCULATION`, `CATALOG_SUPPLY`, `FULFILLMENT`, `FINANCE`, `HEAD`, `VIEWER`), 10 пространств прав, Settings Hub.
- ИИ через LiteLLM и Langfuse, 2 слоя каталога, фиксация курса на дату КП, отклонение маржи.
- **M2-ERP-01**: Приложение `portal` — 25 эндпоинтов портального API (`/api/portal/v1/*`), сессии по Telegram `initData` и magic-link, строгая изоляция компаний, права `CanAct`.
- **M2-ERP-02**: Приглашение в кабинет (`POST /api/v1/accounts/contacts/{id}/invite/`) по email и Telegram, `EmailLog`, регистрация с улицы запрещена.
- **M2-ERP-03**: Публичная страница акцепта КП (`portal.public_views`), 4-значный код подтверждения, 202-генерация PDF с фоновой задачей и `Retry-After: 5`.

**Cabinet (`apps/cabinet`)** — кабинет клиента:
- SPA без бэкенда на React 18 + Vite 7 + Tailwind 4 + shadcn/ui.
- Два режима: Web (magic-link на email, форма нового клиента) и Telegram Mini App (`window.Telegram.WebApp`, тема, viewport, deep-links `deal_<id>`).
- Полный клиентский путь без пробелов (M2-CAB-04): виджет действий «Требует вашего решения», черновики запросов с подбором позиций из каталога (`CatalogPickerDialog`) и вложениями, мультивыбор в каталоге с плавающей плашкой оформления, построчная приёмка и рекламации поставок, загрузка сканов подписанных актов.
- 100% симметрия i18n (`ru`, `uz`, `en`, 422 ключа), 0 нарушений доступности axe (WCAG AA). 213 тестов Vitest.
- Проверен сквозным прогоном глазами на 1440px и 390px (M2-QA-01, отчёт `docs/runbooks/m2_qa_01_report.md`).

**Инфраструктура**:
- `legacy/b2b` полностью удалена (M2-INF-01), полная история сохранена в теге `b2b-final`.
- `make up` поднимает весь ансамбль на `crm.`, `erp.`, `cabinet.localhost`, Caddy, Postgres 17, Redis, RustFS, LiteLLM.
