# Откат промпта
Статус: действует · Владелец: лид · Обновлено: 2026-10-22

## Когда применять
После выкладки изменённого `backend/prompts/*.md` ухудшились ответы: жалобы менеджеров,
рост `fallback`/эскалаций, выдуманные факты, падение faithfulness в Langfuse.

## Диагностика
1. Версия промпта в ходе бота: `prompt_version` (первые 12 символов sha256 файла) — CRM, мета хода; Langfuse — metadata трейса.
2. `git log --oneline -- backend/prompts/` — какой коммит поменял промпт; PR-комментарий eval-gate к нему.
3. Langfuse → Dataset `golden-dialog` → сравнить runs `git-<sha>` до/после.

## Действие
1. `git revert <sha>` коммита с промптом → PR. Job `eval-gate` обязателен (промпт менялся) —
   дождаться зелёного комментария с метриками.
2. Merge → тег `v*` → `deploy-prod.yml` (Фаза 8). На dev: `make up` пересоберёт образ.
3. ⚠️ Срочно, без PR (только prod-инцидент): `git checkout <old_sha> -- backend/prompts/<file>.md`
   на сервере не делать — образ неизменяемый. Откатывать только выкладкой предыдущего тега образа (runbook деплоя, Фаза 8).

## Проверка
`prompt_version` в новых ходах = прежняя версия; метрики Langfuse (faithfulness, fallback) вернулись.

## Эскалация
Автору изменения промпта: примеры диалогов (`lead_id`), eval-отчёт до/после.
