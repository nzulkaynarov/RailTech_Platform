# Переезд dev → prod (PLAN Фаза 9)

## Когда применять
Все гейты Фаз 0–8 отмечены в `docs/PROGRESS.md`; решено запускать пилот.

## Чек-лист (каждый пункт — команда и ожидаемый результат)

- [ ] **Гейты 0–8 закрыты** — в `docs/PROGRESS.md` все ☑.
- [ ] **VPS и выкладка** — по `deploy.md`; тег `vX.Y.Z` → workflow Deploy prod зелёный;
      `make smoke-prod` → «Smoke prod OK».
- [ ] **Реальная KB** — CRM → «База знаний» → загрузить документы; «Тестовый поиск» по 10
      типичным вопросам находит нужный документ в топ-3.
- [ ] **Тексты** — Настройки → `texts`: приветствие и согласие на ru/uz/en утверждены, согласие
      упоминает обработку внешними ИИ-провайдерами; `consent_version` = дата утверждения
      (смена версии заново запрашивает согласие у всех).
- [ ] **Пользователи** — первый админ через `/setup` (код из логов api) или `scripts/create_admin.py --prod --email …`; админ заводит менеджеров
      (временные пароли), роли выданы, у каждого менеджера привязан Telegram (профиль).
- [ ] **Канал** — prod-канал создан, бот — администратор; Настройки → `notifications.channel_id`
      и `duty_user_ids`; `docker compose … exec api python -m app test-alert` → пост в канале.
- [ ] **Webhook** — `scripts/set_webhook.py` → `url: https://<домен>/telegram/webhook`,
      без `last_error`; тестовый диалог с prod-ботом: /start → согласие → вопрос → ответ из KB;
      «позовите менеджера» → пост с кнопкой «Забрать» → забрать → ответить из CRM.
- [ ] **Бэкап** — `scripts/backup.sh --prod`, восстановлен на dev (`backup-restore.md`).
- [ ] **Алерты** — тестовый алерт пришёл (см. «Канал»); в 18:05 — «📊 Итоги дня».
- [ ] **Бюджет** — Настройки → `budget.daily_usd` согласован; лимиты в консолях провайдеров (ADR-0014).
- [ ] **Дежурный** — назначен дежурный менеджер (`duty_user_ids`) и порядок замены.

## Действие при провале пункта
Остановиться, исправить по соответствующему runbook (`bot-silent`, `escalations-missing`,
`deploy`), повторить пункт. Клиентам ссылку на бота не давать, пока чек-лист не закрыт.

## Пилот (4 недели)
- Еженедельно: `scripts/sample_dialogs.py --prod` → разметка → golden (`docs/systems/crm/evals-labeling.md`).
- Первые 2 недели — разбор 100 % эскалаций (CRM → «Лента решений» лида).
- Метрики `docs/systems/crm/BUSINESS.md §10` — по дашборду; отклонения → задачи.

## Эскалация
Владельцу проекта: какой пункт не проходит, что сделано, логи (`make logs s=api`).
