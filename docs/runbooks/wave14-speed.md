## 2. «Готово, когда»

- **S1:** до/после в описании PR (`--durations`, полное время `make check-erp`); число тестов то же; 3 прогона подряд зелёные (нет гонок между воркерами).
- **S2:** таблица «правка → какие задания» в `docs/systems/infra/ci.md`; PR с правкой только `crm.yaml` не запускает ERP; e2e Платформы ≤ 6 мин и 3 прогона без повторов.
- **S3:** тексты правил; `ci_local.sh` пропускает уже зелёную стадию (проверено двумя запусками подряд).
- **S4:** сборка образов параллельно проверена прогоном workflow со сборкой без выкладки (вход `action=build` или `dry_run`), время ≤ 6 мин; прод не трогать — первый реальный автодеплой делает архитектор с разрешения владельца.
- Лид в отчёте: время CI на PR до/после по 3–5 прогонам новых PR.
