# Тестовые компании: отметка и скрытие из рабочих списков
Статус: действует · Владелец: лид · Обновлено: 2026-11-27 (ТЕСТ-1)

## Когда применять

На рабочей базе завелись пробные компании (проверка кабинета, обучение, ошибочные карточки), и они мешают в списках, счётчиках,
панелях и отчётах. Решение владельца 2026-11-27: **пометить как тестовые и скрыть, ничего не удаляя**.

## Что делает отметка

- `parties.Company.is_test` — один флаг, ведёт ERP. Ставит и снимает тот, кто правит реквизиты контрагента (`deal.manage` или
  `supply.manage`): карточка контрагента → «Отметить как тестовую» / «Снять отметку»; действие пишется в журнал.
- Отметка едет в снимке `uz.railtech.erp.company.updated.v1` (`company.is_test`): CRM держит её у клиента (`clients.is_test`),
  EDS — в проекции `company_marks`.
- Из списков, счётчиков, панелей, очередей и отчётов ERP, CRM, EDS и Платформы тестовая компания уходит по умолчанию; видна по
  фильтру «Тестовые» (`?test=only`, `?test=all` — все вместе). Карточка, открытие по номеру, письма и уведомления по ней работают,
  вход её контактов в кабинет не меняется.

## Действие: пометить пачку компаний на проде после выкладки

Команда сначала только считает (dry-run), печатает числа, без названий и данных:

```bash
python manage.py mark_test_companies --ids 12,15,40            # что изменится
python manage.py mark_test_companies --ids 12,15,40 --apply    # поставить отметку
python manage.py mark_test_companies --ids 12,15,40 --unmark --apply   # снять отметку
```

Вывод: `requested`, `found`, `missing` (нет такого id), `already` (уже в нужном состоянии), `to_change`, `changed`. Повтор
безопасен. Перед `--apply` убедитесь, что это нужная база. Отметка пишется в журнал и уходит в CRM и EDS снимком компании.

## Диагностика

- Компания осталась в списке: отметка снята или не дошла до CRM/EDS — проверьте `clients.is_test` (CRM) и `company_marks` (EDS);
  снимок ждёт в журнале шины («Состояние» → шина), порядок — по `company.updated_at`.
- Тестовой компании нет, а нужна: откройте карточку по ссылке из «Тестовых» или по номеру документа.
