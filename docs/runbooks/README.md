# docs/runbooks — эксплуатация и действующие волны агентов
Статус: действует · Владелец: лид · Обновлено: 2026-10-29

Здесь — только то, по чему работают сейчас: инструкции эксплуатации (симптом → диагностика → действие → проверка) и
runbook'и идущих волн. Закрытые волны — [`../history/runbooks/`](../history/runbooks/); отчёты гейтов и прогонов
глазами — [`../audits/`](../audits/README.md).

## Действующие волны агентов

Runbook волны — промпт лида, раунды, задачи с «готово, когда», что параллельно. Преамбула исполнителя —
[`docs/ORCHESTRATOR.md`](../ORCHESTRATOR.md) §4.2; где волна сейчас — [`HANDOFF.md`](../HANDOFF.md) §1 и §3.

| Волна | Этап | Состояние (HANDOFF §3) |
|---|---|---|
| [`wave16-d1-work-screens.md`](wave16-d1-work-screens.md) | D1 — рабочие экраны директора и менеджера | задачи влиты, гейт D1-7 не проведён |
| [`wave17-d2-costing-accounting.md`](wave17-d2-costing-accounting.md) | D2 — расчёт, склад, бухгалтер, D-DOC1 | влиты, кроме D2-8 и B-086; гейт D2-6 не проведён |
| [`wave18a-pilot-critical.md`](wave18a-pilot-critical.md) | необходимое к сокращённому пилоту | раунд 1 влит, остальное не начато |

Волна закрыта (гейт пройден, задачи влиты) — runbook переносится в `../history/runbooks/` с баннером «История», строка
отсюда удаляется. Отчёт гейта новой волны кладётся в [`../audits/`](../audits/README.md), а не сюда.
