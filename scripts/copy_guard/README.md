# Проверка текстов интерфейса (copy guard)

Только стандартная библиотека Python 3.11+. Стандарт — `docs/architecture/ui-standard.md` §13–§14 и словарь
статусов `docs/architecture/status-dictionary.md`; решения владельца 2026-11-25 (без жаргона, должностей, названий
систем, ложных обещаний; клиенту нет «ЭДО»).

| Файл | Что делает |
|---|---|
| `extract.py` | Собирает строки, которые видит человек: каталоги i18n Платформы и Кабинета, строки в `.ts/.tsx` вне каталога, Python-тексты BFF, ERP, CRM, EDS, шаблоны писем и PDF, `django.po`, справку. Не берёт docstring, логи, `console.*`, тесты, миграции; диагностику разработчика перечисляет `DEV_ONLY_SYMBOLS` (точные функции). |
| `copy_guard.py` | `check <repo> --app <app> --baseline <файл> [--update] [--show]` — режим теста и CI; `audit` — выгрузка находок в CSV. |
| `wordlists/*.tsv` | Правила, один класс на файл: regex (без учёта регистра; `(?-i:…)` — с учётом), важность H/M/L, языки, аудитории, подсказка, основание. |
| `allow.tsv` | Объяснённые ложные тревоги: regex ключа (полное совпадение, без `.*`), класс, причина (обязательна). |
| `baseline/<app>.json` | Находки, которые ещё не исправлены. Только L; список только сокращается. |
| `curated.tsv` | Готовые формулировки «было → стало» для выгрузки `audit`. |

## Как работать

- Тест `scripts/tests/test_copy_guard_<app>.py` идёт в шаге CI `python3 -m unittest discover -s scripts/tests`. Он красный, если
  появилась находка не из списка, если исправленная ещё в списке, если в списке есть H или M, или если список или `allow.tsv`
  стали длиннее потолка в тесте.
- Новая находка — исправь текст. В список её не добавляют.
- Исправил текст — `python3 -I scripts/copy_guard/copy_guard.py check . --app cabinet --baseline scripts/copy_guard/baseline/cabinet.json --update`
  и опусти потолок `BASELINE_CEILING` в тесте до нового числа.
- Ложная тревога — поправь правило или добавь строку в `allow.tsv` с причиной (число строк тоже ограничено потолком).
- `--show` печатает H и M находки с текстом.

## Где системные слова и бренды разрешены

`ctx=settings`: Настройки · Подключения, журнал шины и аудита, состояние системы. Должности не проверяются в каталоге
ролей и в «Что нового». Юридические тексты (договор партнёра, оферта, политика, согласие) получают важность L и пометку D10:
их правит держатель зоны «Право».

## Приложения

Подключено: `cabinet`. Следующие PR добавляют `platform`, `erp`, `crm`, `eds`, справку: каждый — свой тест и свой базовый список.
