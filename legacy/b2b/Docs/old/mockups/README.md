# Макеты экранов — АРХИВ (снимок на 2026-07)

Перенесено из `Docs/business/mockups/` 2026-08-21. Это точечный снимок раннего дизайна, а не
действующая спецификация.

## Почему в архиве

Макеты рисовались **до** решения о валюте и показывают суммы в USD: «$248 700», «$84 500»,
«Без НДС $756 473 / С НДС (12%) $847 250». Продукт с 06-07 работает по правилу **UZS-canonical**
(`CLAUDE.md`, раздел Key Architecture Decisions): `currencyStore` форматирует UZS,
`Quote.quote_currency` по умолчанию UZS, валюта представления КП зафиксирована на UZS, потому что
движок себестоимости считает в UZS. Там же прямым текстом: «Do NOT revert to USD».

Расхождение нашёл граф знаний: при съёмке 21-08 шесть из семи предложенных им вопросов оказались
вида «как связаны „цены в USD в макете" и „решение UZS-canonical"» — то есть граф видел
противоречие между макетом и кодом и не мог его разрешить.

## Что в них ещё годится, а что нет

| Годится | Не годится |
|---|---|
| Композиция экранов, плотность, расположение блоков | Любые суммы и знак валюты |
| Набор виджетов дашборда как идея | Конкретные цифры метрик |
| Группировка каталога по доменам | Колонка базовой цены FCA в показанном виде |

**Правило простое: макет — про раскладку, а не про правду.** Числа, валюту, статусы и названия
полей брать из кода и из `CLAUDE.md`, а не отсюда.
