## Что вошло

### Волна A — страница КП для клиента (проверена глазами end-to-end)
- Публичный эндпоинт `GET /api/v1/public/quotes/<token>/` теперь **content-negotiated**: браузер
  (`Accept: text/html`) → серверная HTML-страница `crm/quote_public_page.html` (mobile-first, без
  логина); `?export=pdf`/скачивание → тот же клиентский PDF. Переиспользует `client_projection_items`
  (себестоимость/маржа НЕ течёт — тот же helper, что у PDF).
- **Офлайн-принятие по email-коду**: `QuoteAcceptanceCode` (sha256-хэш, TTL 15м, 5 попыток,
  single-use, `hmac.compare_digest`, `select_for_update`); эндпоинты `request-code` (5/час) /
  `accept` (10/мин) / `reject` / `viewed`; email резолвится ИЗ СДЕЛКИ (не запроса) → enumeration-
  neutral; IDOR-scoped; burn+accept в одной транзакции. Копирайт честен: «коммерческий акцепт... это
  НЕ электронная подпись; договор подписывается отдельно» (E-IMZO не реализован). Аудит: email+IP.
- **`quote.viewed`** через JS-маячок (POST, не голый GET — против сканеров почты), дедуп по
  `Quote.first_viewed_at`; таймлайн-событие + уведомление продавцу.
- **Кабинет покупателя**: после «Одобрить» вместо выброса на дашборд — панель «Предложение принято →
  договор № … → [Перейти к договору]» (`BuyerAcceptedPanel`, реальный contract id).
- Eyes-on прогон: публичная страница → код 145182 из письма → «Договор CT-2026-00003 готовится к
  подписанию». Бэкенд: quote APPROVED (approved_by NULL), deal CONTRACT_SIGNED, контракт материализован.
