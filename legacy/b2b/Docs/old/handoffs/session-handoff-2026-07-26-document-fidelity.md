## ОТКРЫТО: PR #415 — аудит дизайна документов (ЖДЁТ УТВЕРЖДЕНИЯ владельца)
Канон: `Docs/dev/specs/spec-document-design-audit-2026-07-26.md`. Все 5 PDF отрендерены с ПОЛНЫМ
брендом + все 5 клиентских писем, глазами. Вердикт: фундамент крепкий, «дилетантскость» = дыры

  недействителен), «от , » без даты — supplier резолвится только через contract→quote, ручной
  инвойс Wave G его теряет → нужен fallback source_quote → deal.seller_routing.
- Договор (5/10): §10 «Реквизиты и подписи Сторон» БЕЗ реквизитов; итог без НДС-разбивки.
- КП (7/10): пустая стр.2; cover-letter «…сотрудничеству, .» (пустой {{buyer}} не чистится);
  {{deal}} получает № КП вместо заявки; дубль реквизитов шапка↔ПОСТАВЩИК; пустой бокс ПОКУПАТЕЛЬ.
- Акт (7/10): «Итого» без НДС-разбивки. Письмо-документ (6/10): заголовок ×2, нет блока подписи.
- Email (6/10): сумма БЕЗ валюты; «по сделке №32» вместо № КП; бренд платформы вместо продавца
  (white-label паттерн Stripe/DocuSign); invite без имени приглашающей компании; вложенные «ёлочки».
- Сквозное: **3 разных формата итогов НДС** в 4 документах.
**План (в спеке): Волна D0** (контент-P0, ~день) + **Волна D1** «Документный дизайн 2.0» (P1, 1–2 дня).
