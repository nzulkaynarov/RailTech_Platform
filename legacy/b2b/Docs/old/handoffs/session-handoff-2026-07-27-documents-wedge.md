## Ключевые уроки/гочи сессии
- **CSS-комментарии НЕ вкладываются** — `/* … /* … */` закрывается на первом `*/`, хвост убивает
  следующие объявления. Проверять CSS ПАРСЕРОМ (tinycss2), не текстом. Плюс: Django `{# #}` —
  только однострочные (многострочные утекают в вывод — ловилось трижды: #410, #413, #417).
- **Валюта себестоимости** = UI-«сид» для НОВОЙ строки, движок ключуется на per-line
  `frozen_currency`; настройка не переваллютирует существующие строки — по дизайну.
- **Реквизиты на проде ЗАПОЛНЕНЫ** (владелец 27-07: «давно внесены») — handoff 26-07 «профиль
  пуст» УСТАРЕЛ, не спрашивать повторно.
- **Процесс:** benchmark-first обязателен ДО кода (владелец поймал старт правок типографики без
  показанного плана — план предъявлен постфактум). Спеки-на-утверждение: #422, #427 (обе уже утв.).
