## W1 — Уязвимости в прод-локе — ✅ СДЕЛАНО 14-08

- **Факт:** `pip-audit` по окружению backend-образа: `cryptography 49.0.0` (PYSEC-2026-3552, фикс 50.0.0) и `tablib 3.9.0` (CVE-2026-9318, фикс 3.10.0). Джоба `security` упадёт на этом сразу после оживления CI.
- **Разведано:** флоры в `requirements.in` уже позволяют обе версии (`cryptography>=45`; tablib приезжает через `django-import-export>=4.4`, стоит 4.4.1 — кап на tablib не объявляет). Скорее всего хватит чистой перекомпиляции локов без правки `.in`.
- **Как (INF-05):** linux py3.12 + `gcc` + `libpq-dev` + `pip-tools==7.5.3`; рецепт — в джобе `deps-lock`:
  ```
  pip-compile --quiet --generate-hashes --no-strip-extras --output-file=requirements.txt requirements.in
  pip-compile --quiet --generate-hashes --no-strip-extras -c requirements.txt --output-file=requirements-dev.txt requirements-dev.in
  ```
  Среда — одноразовый контейнер от python:3.12 (рантайм-образ backend не годится: gcc живёт в builder-стадии).
- **Проверка:** пересобрать образ, `make security-backend` → 0 находок; `make test` (cryptography мажорно скакнула 49→50 — прогнать 2FA/Fernet-тесты обязательно: секрет TOTP шифруется Fernet).
- **Как вышло:** чистой перекомпиляции НЕ хватило (pip-compile без `--upgrade` бережёт существующие пины, потому лок и протух), а `--upgrade` поднял бы ~40 пакетов (DRF 3.17→3.18, unfold 0.100→0.104, Django 6.0.7→6.0.8) — при мёртвом CI это неприемлемый радиус. Точечный `--upgrade-package cryptography` тоже не сдвинулся: **`pyopenssl==26.3.0` требует `cryptography<50`**. Итог — связка из ТРЁХ пакетов: `cryptography 49.0.0→50.0.0`, `pyopenssl 26.3.0→26.4.0`, `tablib 3.9.0→3.10.0`, больше ничего.
- **Проверено:** `make security-backend` → `No known vulnerabilities found`; плоская пересборка локов (как в джобе `deps-lock`) даёт нулевой дрейф — гейт стабилен; образ пересобран, 90 точечных тестов (2FA/Fernet/sessions/auth/import-export) зелёные; полный прогон зелёный.
- **Осталось на будущее:** ~40 пакетов отстают от актуальных (это НЕ уязвимости, а дрейф). Общий апгрейд — отдельная осознанная волна с живым CI, не попутно.
