# D2-хвост: платежи и отгрузки в реестре документов (бенчмарк + план)

_Дата: 2026-08-01. Остаток волны D2 (#489): «у платежей нет карточки документа (регистр
записей, а не документ), у отгрузок своя статусная лента — обоим нужно продуктовое решение»._

## 1. Эталоны

| Эталон | Паттерн | Суть |
|---|---|---|
| **Odoo / QuickBooks** | Register payment + **Payment Receipt** | Платёж — ЖУРНАЛЬНАЯ ЗАПИСЬ (регистр), не документ. Печатный артефакт — квитанция об оплате, генерится ПО платежу кнопкой/после оплаты и уходит клиенту |
| **Odoo Inventory** | Delivery order + **Delivery Slip** | Отгрузка — операция со своей статусной лентой (не документ). Печатный артефакт — накладная (delivery slip: позиции, количества, № заказа), генерится при валидации |

**Общий знаменатель:** регистры остаются регистрами. В документооборот попадает их
**печатный артефакт** — квитанция и накладная, — а не сама запись. Ни один эталон не
натягивает платёж/отгрузку на каркас документа (отсутствие фичи — тоже решение).

## 2. Gap-анализ

| Аспект | Эталон | У нас | Решение |
|---|---|---|---|
| Платёж в реестре | не документ; есть квитанция | Payment — регистр без печатной формы | **D2a**: «Квитанция об оплате» — PDF по механике E1 (вид RECEIPT, образец миграцией, блоки {{doc.*}}); кнопка на платеже; письмо покупателю опционально (в 4 письма G3 уже входит «оплата получена»?) — проверить, не плодить 5-е |
| Отгрузка в реестре | не документ; есть накладная | Fulfillment — статусная лента без печатной формы | **D2b**: «Накладная на отгрузку» (DELIVERY_NOTE) — PDF по E1-механике, генерится по отгрузке; основание приёмки для двустороннего акта (G1: «принцип двух рук») |
| Реестр документов | показывает артефакты | DocumentRegistry: договоры/счета/акты | квитанции и накладные добавить В РЕЕСТР как документы; Payment/Fulfillment СТРАНИЦЫ остаются регистрами |

## 3. Вердикт

Применяем паттерн **«регистр + печатный артефакт»** (Odoo). НЕ делаем: карточку документа
для платежа, статусы документа у отгрузки, новые письма без ревизии лимита «ровно четыре»
(G3). Волны: **D2a** (квитанция), **D2b** (накладная), **D2c** (оба вида в реестре).
Механика вся готова (E1–E4): виды шаблона, образцы миграцией, блоки, снапшот.
