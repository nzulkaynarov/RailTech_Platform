## Топ-5 критических проблем

### 1. [CRITICAL] Кнопка "Выйти" не работает
- **Файл:** `layouts/AppShell.tsx:535`
- **Проблема:** `<DropdownMenuItem>` без `onClick` — клик ничего не делает
- **Влияние:** Пользователь не может выйти из системы

### 2. [CRITICAL] Белый экран если activeStatus не задан
- **Файл:** `pages/Dashboard.tsx:515-517`
- **Проблема:** Три условных рендера `{activeStatus === 'X' && ...}` без fallback
- **Влияние:** Пустая страница без объяснения

### 3. [CRITICAL] Браузерная навигация (назад/вперёд) не работает в основном приложении
- **Файл:** `App.tsx` (MainApp)
- **Проблема:** Навигация через `useState<Page>` без `pushState` — URL не меняется
- **Влияние:** Кнопка "назад" уводит пользователя с сайта

### 4. [CRITICAL] Password Setup — заблокированная кнопка без объяснения
- **Файл:** `Auth/PasswordSetupPage.tsx:64-67, 169`
- **Проблема:** При невалидном uid/token кнопка Submit disabled, но нет сообщения об ошибке
- **Влияние:** Пользователь застревает на странице без понимания что делать

### 5. [HIGH] 60+ нарушений дизайн-системы: хардкод цветов
- **Файлы:** 25+ компонентов
- **Проблема:** `text-white`, `bg-amber-500`, `bg-emerald-600` и т.д. вместо семантических токенов
- **Влияние:** Несогласованность тёмной/светлой тем, невозможность централизованно менять палитру

## Реестр проблем по категориям

### A. Клиентский путь (User Journey)

#### [CRITICAL] A.1 Logout не работает
- **Расположение:** `layouts/AppShell.tsx:535`
- **Категория:** Клиентский путь -> Тупик
- **Описание:** DropdownMenuItem "Выйти" не имеет onClick handler. Клик не вызывает logout().
- **Решение:** Добавить `onClick={() => { logout(); window.location.href = '/'; }}`

#### [CRITICAL] A.2 Dashboard пустой при невалидном activeStatus
- **Расположение:** `pages/Dashboard.tsx:515-517`
- **Описание:** Нет fallback — если activeStatus не BUYER/SELLER/MANUFACTURER, рендерится пустота.
- **Решение:** Добавить `default` case: `<BuyerDashboard>` как fallback.

#### [HIGH] A.3 Dashboard молча глотает ошибки API
- **Расположение:** `pages/Dashboard.tsx:473`
- **Описание:** `.catch(err => console.error(...))` — нет UI-отображения ошибки.
- **Решение:** Добавить state `error` и показывать `<Alert variant="destructive">`.

#### [HIGH] A.4 Графики рендерятся пустыми без сообщения "Нет данных"
- **Расположение:** `pages/Dashboard.tsx` (все 3 варианта)
- **Описание:** Recharts рендерит пустой SVG при нулевых данных — выглядит как баг.
- **Решение:** Условный рендер: `{data.length > 0 ? <BarChart> : <EmptyState>}`

#### [MEDIUM] A.5 LoginPage onNavigate — заглушка
- **Расположение:** `App.tsx:164`, `Auth/LoginPage.tsx:43`
- **Описание:** Callback `onNavigate={() => {}}` — noop, реальная навигация через side effect.
- **Решение:** Убрать неиспользуемый проп.

#### [MEDIUM] A.6 KYCRegistrationForm — хрупкая навигация через DOM
- **Расположение:** `Auth/KYCRegistrationForm.tsx:210-216`
- **Описание:** `window.history.pushState` + `dispatchEvent(popstate)` вместо React-навигации.
- **Решение:** Принять `onBack` callback через пропсы.

### B. Компонентные нарушения

#### [HIGH] B.1 Нативные HTML-элементы вместо shadcn
- 4 raw `<button>` (PlaceholderPages.tsx:870,1081; AppShell.tsx:379,478)
- 5 raw `<input>` (CompanyProfile.tsx:192; AdminNomenclature.tsx:130,175,212; KYCManagerDashboard.tsx:156)
- 14 raw `<table>` в PlaceholderPages, CatalogTable, QuoteBuilderGrid, AdminUsers и др.
- **Решение:** Заменить на `<Button>`, `<Input>`, `<Table>` из shadcn/ui.

#### [HIGH] B.2 60+ хардкод цветов вместо токенов
- `text-white` → `text-foreground` / `text-primary-foreground`
- `bg-amber-500` → Нужен semantic token (warning)
- `bg-emerald-500` → Нужен semantic token (success)
- `bg-red-500` → `bg-destructive`
- **Файлы:** StatusBadge.tsx, flowStore.ts, ManagerDashboard.tsx, AdminDashboard.tsx, ProductCard.tsx, ThemeToggle.tsx, TopLoadingBar.tsx, NotificationCenter.tsx и др.

#### [MEDIUM] B.3 Inline styles для динамических цветов
- `Dashboard.tsx:196,350` — `style={{ backgroundColor: ... }}`
- Допустимо для data-driven, но статические цвета должны быть из темы.

### C. i18n — захардкоженный текст

#### [HIGH] C.1 Русский текст без t()
- `AppShell.tsx:644-654` — "Уведомления", хардкод нотификаций
- `flowStore.ts:142-149` — стадии сделок на русском
- `ManagerDashboard.tsx:65-70,176-177` — сравнение с русскими строками
- `PlaceholderPages.tsx` — DemoRequestCard, SourcingImportPage с моковыми данными

#### [MEDIUM] C.2 PageBreadcrumb с хардкод labels
- `Shared/PageBreadcrumb.tsx:23-45` — 24 русских лейбла вне i18n

### D. Адаптивность и доступность

#### [MEDIUM] D.1 Таблицы не адаптированы для мобильных
- 14 raw `<table>` без responsive обёрток
- shadcn Table + ScrollArea решили бы проблему

#### [LOW] D.2 Отсутствие aria-label у иконок-кнопок
- Многие `<Button size="icon">` без aria-label
- Скринридеры не понимают назначение кнопки

### E. Производительность

#### [MEDIUM] E.1 ProductManagement и ProductDetail используют mock-данные
- `pages/ProductDetail.tsx:40-45` — `import { products } from '@/data/products'`
- Данные не из API — заглушка для демо
