## Грабли, найденные по дороге (уже учтены, но помнить)

- **`hs_code` молча выбрасывался DRF** — поля не было в `fields` сериализатора; UI говорил
  «сохранено», БД оставалась пустой. Нашлось только глазами + проверкой БД.
- **Лексика таможни ≠ лексика продавца**: «стрелочный перевод» в номенклатуре зовётся «рельсы
  переводные, крестовины…» → поиск через per-word `TrigramWordSimilarity` (OR по словам) +
  первичное ранжирование по листовому сегменту имени (имена ГТК — пути через «:»).
- **Параллельный агент работает в этом же working tree**: 2026-08-04 его checkout между моими
  шагами увёл HEAD на его ветку, и мой коммит лёг туда (симптом — «No commits between main and
  branch» при создании PR). Лечение: `git branch -f <его-ветка> <его-tip>` + cherry-pick своего
  коммита на свою ветку. **Перед commit/push всегда `git branch --show-current`.**
