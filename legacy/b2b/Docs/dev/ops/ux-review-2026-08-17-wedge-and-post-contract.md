## Наблюдения для владельца (не чинил — продуктовые/данные)

- **O1. Отказ по публичной ссылке не требует кода**, акцепт требует. Как в PandaDoc/Qwilr (decline по ссылке), но асимметрия означает: любой, кому переслали ссылку, может отклонить КП (последствие обратимо — сделка в CALCULATING, продавец переотправляет). Решение — оставить или ставить код и на отказ.
- **O2. «Create new version» создаёт пустой по ценам черновик** (строки заявки, стоимость 0). Odoo/PandaDoc «new revision» копирует прошлую версию. Рядом есть «Duplicate» (глубокая копия) — либо объединить, либо переименовать, чтобы продавец понимал разницу.
- **O3. Счёт печатается без банковских реквизитов**, если у продавца пуст `bank_details` — без предупреждения (Odoo блокирует/подсказывает). Кандидат в правило «полнота профиля перед выставлением».
- **O4. Дашборд покупателя показывает сделку «Completed» сразу после CLOSED_WON**, хотя ни оплаты, ни поставки ещё нет (это лейбл стадии). Слово путает: покупатель ещё должен платить и принимать.
- Мелочь a11y: `SelectTrigger` единицы в редакторе заявки без `aria-label`.
