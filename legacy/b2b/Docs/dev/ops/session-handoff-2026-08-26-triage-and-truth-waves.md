## 2. Главное, что стоит унести из сессии

### Скептики ДВАЖДЫ нашли зазор в предыдущей починке

1. **Находка 64.** Она мерила `/admin/crm/dealstage/`, а закрывался `master_data` — и в теле
   #612 было написано «в админке зазора не было». Замер показал: у не-суперпользователя **с
   модельными правами** открыты **32 админки из 60**, включая журнал активности (13 полей из
   18 — саму историю, по которой разбирают инцидент), историю правок КП, все справочники FSM,
   `auth.Group` и `auth.Permission`. Последнее — путь самовыдачи «второго ключа», на котором
   стоит гейт мастера компаний из #599.
2. **Находка 58.** Инвалидацию кэша справочников в #603 повесили на **путь записи** (хуки
   вьюсета), а не на запись модели: правка из инженерной админки до десяти минут не доходила до
   арендаторов.

**Вывод:** проверять надо **починку**, а не только находку — и формулировку находки тоже.
Трижды за триаж симптом был верен, а названная причина — нет.

### Режим инспекции стал правилом САЙТА, а не свойством классов

Раздавать миксин руками по классам — механика, которая уже разъехалась (24 класса без него,
25-й появился бы незамеченным). Теперь `EngineeringAdminSite.register()` надевает режим на
всё, что в нём регистрируют, включая админки сторонних приложений (`django_celery_beat`,
`token_blacklist`). Замер после: **0 открытых из 60**, суперпользователь не потерял ничего.

Заодно закрыты два обхода: `list_editable` (правка прямо в реестре шла мимо `readonly_fields`)
и отбор массовых действий по `__wrapped__` (признак `functools.wraps`, а не намерения автора —
обычный `@admin.action` проходил насквозь).

### Ловушки проверок, пойманные на себе

- **Проба гарда оказалась ПУСТОЙ.** `black` переформатировал строку в одну, подстрока в
  скрипте отката не совпала — «тест не упал» едва не сошло за «гард не нужен». Теперь любая
  проба идёт с `assert old in s`.
- **Заготовка теста мерила не тот сценарий.** Тупик с подсказкой живёт только при ОПЛАЧЕННОМ
  счёте; при неоплаченном цепочка честно зовёт платить (счёт идёт раньше отгрузки).
- **gettext придумал перевод, ПРОТИВОПОЛОЖНЫЙ смыслу.** Письму об отказе по KYC —
  «KYC has been verified», с флагом `fuzzy`. Django такие игнорирует, но снятый не глядя флаг
  выдал бы поздравление вместо отказа. Проверять **рендером письма** в обеих локалях.
- **Жёсткие паузы в тестах** проверяют скорость машины, а не поведение — только `waitFor`.
- **Ключ i18n снова падал в чужой раздел** (`remove`, `noData`, `empty`, `activated`
  встречаются в нескольких блоках). Вставка обязана спускаться ПО ПУТИ разделов, проверка —
  разбором JSON, не подстрокой.
- **Пересборка JSON расэкранирует кавычки по всему файлу** — вставлять точечно, иначе дифф
  тонет в шуме.
- **Черновая правка regex'ом уронила контейнер** синтаксической ошибкой — после каждой
  автоправки `ast.parse`.

### Гард поймал неполноту ДО мержа

`frontend/src/i18n/__tests__/activityCoverage.test.ts` читает коды событий **из исходников
бэкенда** и определяет нужный словарь по тому, ЧТО пишет вызов: журнал → `activity.*`,
уведомление → `notification.*`. Четыре новых кода имели подписи в `activity`, а нужны были в
`notification` — «есть хоть где-нибудь» не считается, подпись в чужом пространстве имён не
печатается. Ровно тот класс, ради которого гард и писали.

## 4. Рабочие заметки для следующей сессии

- **Egress Docker Desktop протухает каждые 30–40 минут.** `security` и `deps-lock` падают с
  `ConnectTimeoutError` к pypi. Лечение: перезапуск Docker → проверка **настоящего HTTPS
  изнутри контейнера** (`urlopen`, не DNS) → повтор только упавшего гейта. Один раз падение
  было иным — `npm audit` на ХОСТЕ, без единого таймаута в логе; отличать по логу, а не по
  привычке.
- **Отчёт `.ci-local/report.md` остаётся от прошлой волны.** Ждать СОБЫТИЯ завершения прогона,
  а не появления файла — иначе можно объявить зелёным то, что ещё идёт.
- **Правки во время `ci-local` красят чужие гейты.** Прогон запускать на финальном дереве.
- `api-contract` краснеет законно, когда волна меняет сериализаторы или `filterset_fields`;
  схема перегенерируется гейтом и коммитится вместе с волной. `capabilities` — метод-поле, его
  внутренние ключи spectacular не описывает, поэтому правки `/me` дрейфа не дают.
