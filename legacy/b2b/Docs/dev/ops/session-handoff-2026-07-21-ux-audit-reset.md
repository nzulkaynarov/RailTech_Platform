- **Семантика денег** (важно, не перепутать при редизайне): вводимый `margin_percent` — это НАЦЕНКА (markup, `×(1+X%)` на себестоимость); порог `below_floor` — по валовой МАРЖЕ (profit/price); «Таможня» (`customs_duty`) — абсолютная сумма за единицу в валюте строки, НЕ процент (`landed=(base+customs)×fx`).
- **Среда:** workflow «CI» (тесты/линт) мёртв по GitHub billing — все гейты локально (`npm run build` + vitest + pytest в контейнере); workflow «Deploy b2b.railtech.uz» ЖИВ и катит на прод при каждом push в main (очередь, cancel-in-progress: false).
