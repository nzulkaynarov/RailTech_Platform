## 1. Решение владельца и новый рабочий режим

**Биллинг GitHub Actions НЕ оплачивать.** GitHub-hosted раннеры (`ci.yml`, nightly e2e) не стартуют — джобы «fail» за 2 с с нулём шагов. Self-hosted деплой **работает** (подтверждено 3 прогонами сегодня, ~55 мин без кэша).

Протокол мержа — `Docs/dev/ops/merge-without-ci.md`:
1. `make ci-local` — зеркало всех 11 джоб одной командой (`scripts/ci_local.sh`), таблица в `.ci-local/report.md`;
2. таблицу — в тело PR;
3. `gh pr merge N --squash --delete-branch`;
4. дождаться деплоя, проверить прод снаружи (хеш бандла, `/health/`, версии зависимостей);
5. если PR трогал UI — `make e2e-prod` (prod-safe Playwright с хоста, замена лежащего nightly) + сценарий глазами.

Ловушка дня: **deps-lock давал ложный OK**, когда pip-compile падал по сети (файлы не переписаны → `git diff` пуст). Скрипт теперь сверяет код выхода контейнера И mtime обоих локов. Docker Desktop на этой машине: egress из VM протухает через минуты — `pkill -9 -f com.docker; open -a Docker`.
