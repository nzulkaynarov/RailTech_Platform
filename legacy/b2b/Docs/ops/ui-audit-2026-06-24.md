# UI audit & remediation plan — 2026-06-24

Full-UI audit across roles. Method: (a) **browser sweeps** (Dockerized Playwright, real
login per role, every page screenshotted + console/HTTP errors + raw-i18n-key detection),
(b) **multi-agent static code audit** (6 dimensions: hardcode, non-shadcn UI, i18n, dead
code, TS hacks, flow — 47 findings). This file is the remediation backlog; fix in waves,
each verified in-browser.
