# Check i18n

Найди отсутствующие переводы и проблемы интернационализации.

## Аргумент

$ARGUMENTS — (опционально) путь к файлу или директории для проверки. По умолчанию — весь `src/`

## Инструкции

### 1. Загрузи файлы локализации

Прочитай:
- `src/i18n/locales/ru.json`
- `src/i18n/locales/en.json`

### 2. Найди все использования `t()` в коде

Поищи паттерны:
- `t('key.path')`
- `t("key.path")`
- `t('key.path', { ... })`
- `` t(`key.${dynamic}`) `` — отметить как динамические ключи

### 3. Проверь по чеклисту

#### Отсутствующие ключи
- [ ] Ключи, используемые в коде через `t()`, но отсутствующие в `ru.json`
- [ ] Ключи, используемые в коде через `t()`, но отсутствующие в `en.json`
- [ ] Ключи, присутствующие в `ru.json`, но отсутствующие в `en.json` (и наоборот)

#### Неиспользуемые ключи
- [ ] Ключи в `ru.json`, которые не используются ни в одном компоненте
- [ ] Ключи в `en.json`, которые не используются ни в одном компоненте

#### Хардкод текста
- [ ] Строки на русском языке прямо в JSX (не через `t()`)
- [ ] Строки на английском языке в JSX (не через `t()`)
- [ ] `placeholder`, `title`, `aria-label` атрибуты с хардкод текстом

#### Проблемы с интерполяцией
- [ ] `t()` вызовы с параметрами, но ключ не содержит `{{variable}}`
- [ ] Ключи с `{{variable}}`, но `t()` вызывается без параметров

### 4. Выведи отчёт

```
## i18n Audit Report

### Отсутствующие переводы
| Ключ | Файл использования | Отсутствует в |
|------|-------------------|---------------|
| auth.title | LoginPage.tsx | en.json |

### Рассинхрон между языками
| Ключ | Есть в | Нет в |
|------|--------|-------|
| ... | ru.json | en.json |

### Хардкод текст (нужна интернационализация)
| Файл | Строка | Текст |
|------|--------|-------|
| LoginPage.tsx:42 | `<h1>Вход</h1>` | "Вход" |

### Неиспользуемые ключи
- `old.unused.key` (ru.json, en.json)

### Динамические ключи (требуют ручной проверки)
- `t(\`status.${status}\`)` в StatusBadge.tsx
```

## НЕ вноси изменения автоматически — только отчёт.
