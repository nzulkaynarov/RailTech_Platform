# Lint & Fix

Проверь код и автоматически исправь найденные проблемы.

## Инструкции

1. Запусти **полную** проверку сборки (НЕ `lint:tsc`, а именно `build` — он строже):
   ```bash
   npm run build
   ```

2. Если есть ошибки типов:
   - Прочитай каждый файл с ошибкой
   - Исправь ошибки типов (неправильные типы, отсутствующие импорты, несовместимые интерфейсы)
   - **Удали** неиспользуемые импорты и переменные (НЕ добавляй `_` префикс — `tsc -b` всё равно ругается)
   - Повторно запусти `npm run build`

3. Проверь соответствие дизайн-системе (CLAUDE.md → Styling Rules):
   - Нет `text-industrial-*`, `bg-industrial-*`, `border-industrial-*`
   - Нет `text-[10px]` или других `text-[Npx]` — только `text-xs`, `text-sm` и т.д.
   - Нет хардкод hex-цветов (#4f46e5) в TSX — только `var(--color-chart-N)`
   - Нет emoji в коде
   - Все формы используют shadcn Input/Textarea/Button (не raw HTML)

4. Проверь соответствие конвенциям проекта:
   - Импорты через `@/` alias (не относительные `../../`)
   - Компоненты в PascalCase
   - Хуки с `use` префиксом
   - `cn()` для условных классов (не конкатенация строк)
   - Все UI тексты через `t()` (не хардкод)

5. Выведи итог: сколько файлов проверено, сколько ошибок найдено и исправлено.

## Не делай

- Не добавляй комментарии или docstrings к коду который не менялся
- Не рефактори код который работает корректно
- Не меняй форматирование файлов которые не содержат ошибок
