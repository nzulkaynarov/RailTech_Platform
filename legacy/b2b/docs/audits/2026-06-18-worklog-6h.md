### Отложено (требует вашего решения / нельзя протестировать здесь)

- [!] **W5.1 Гейт deploy на CI** — НЕ применял автономно: смена триггера production-деплоя необратима, ошибка имени workflow тихо отключит деплой. Точный рекомендуемый сниппет для `deploy-b2b.yml` (CI-workflow называется `"CI"`):
  ```yaml
  on:
    workflow_run:
      workflows: ["CI"]
      types: [completed]
      branches: [main]
    workflow_dispatch:
  jobs:
    deploy:
      if: ${{ github.event.workflow_run.conclusion == 'success' || github.event_name == 'workflow_dispatch' }}
      steps:
        - uses: actions/checkout@v4
          with:
            ref: ${{ github.event.workflow_run.head_sha || github.ref }}
  ```
  (Важно: `workflow_run` по умолчанию чекаутит дефолтную ветку — обязателен явный `ref: head_sha`, иначе задеплоится не тот коммит.)
