# Статья помощи

Правило — ORCHESTRATOR §7 п. 4 (W-REL, «помощь — в том же диффе»). Не база знаний бота: формат БЗ — `docs/kb/FORMAT.md`,
здесь — окно «?» и раздел «Помощь» Платформы.

## Шаги

1. Найди статью экрана по адресу: `grep -l "<адрес экрана>" docs/kb/help/*.md` (поле `screens: [/crm/leads, …]`).
2. Правь текст человеческим языком, по ролям, без терминов кода: что видит, что может, что изменилось. Новый пункт меню —
   новая статья обязательна (иначе красный `features/help/articles.test.ts`). Front matter новой статьи — по образцу
   соседней: `title`, `sections`, `order`, `screens`.
3. `make -C apps/platform kb-sync` — копия в `apps/platform/web/src/generated/` (коммитится).
4. Мягкая проверка: `python3 scripts/help_freshness.py --base origin/main` — предупреждения о тронутых экранах без статьи.
5. В описании PR — строка «Для пользователей (кому): одна-две фразы» (без скобок — для всех); пользователи разницы не
   заметят — строку удалить. Из неё после выкладки собирается «Что нового» (`scripts/release_notes.py`).
6. `docs/kb/help/roadmap.md` («Что ожидается») ведёт архитектор — не правь.
