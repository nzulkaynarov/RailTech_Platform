# Ревью PR

Правила — ORCHESTRATOR §4.1 («Ревьюер ≠ исполнитель», «Тесты конкурентности — с мутационной проверкой»), §3, §7.

## Шаги

1. **Свой worktree**, не основной checkout:
   `git fetch origin <ветка> && git worktree add --detach .claude/worktrees/review-<n> origin/<ветка>`.
2. **Что читать**: «готово, когда» задачи, описание PR (`gh pr view <n>`), дифф `git diff origin/main...origin/<ветка>`,
   CONVENTIONS затронутых систем. Переписку исполнителя не читать.
3. **«Готово, когда»** — каждый пункт: доказательство есть и убеждает (тест проверяет именно это; снимок показывает
   именно это) или ✗.
4. **Инварианты §3**, которые задевает дифф:
   - зона одной системы (§4);
   - контракт раньше кода, обе стороны в PR, версия по §4.1;
   - нет общих таблиц, интеграции только через шину, один владелец у поля;
   - идентификаторы в инструменты агентов — только из подписанного контекста;
   - клиент видит только опубликованный слой — негативные тесты (чужая компания → 404, без контекста → 401);
   - секретов нет; модели — только через LiteLLM по алиасам;
   - документация только в `docs/`; помощь и «Для пользователей» при изменении экрана;
   - снимки 1440 и 390 и axe в `docs/screens/<задача>/` для UI.
5. **Процесс**:
   - миграции по `db-migration`;
   - трейлер в каждом коммите: `git log origin/main..origin/<ветка> --format='%h %s%n%b' | grep -c Co-Authored-By`;
   - `docs/PROGRESS.md` исполнитель не правил;
   - тест блокировки, гонки или параллельных сессий есть, а раздела «Мутационная проверка» нет — вернуть.
6. **Тесты** — только затронутые (таблица скилла `pre-pr`), в своём worktree (`make -C apps/<app> install` перед этим).
   Полный прогон не повторять — это делает CI.
7. **Встроенные проверки**: `/code-review` на дифф; для входа, прав, RBAC, портального API, токенов и вебхуков — ещё
   `/security-review`. Находку берёшь, только если сам проследил реальный путь до сбоя.
8. **Вердикт** лиду:
   ```
   PR #<n> <ID>: ПРИНЯТЬ | ВЕРНУТЬ
   1. <файл:строка> — что не так → что требует «готово, когда» / правило (ссылка)
   Проверено: <тесты, команды>
   ```
   Стиль сверх CONVENTIONS — не повод вернуть.
9. `git worktree remove .claude/worktrees/review-<n>`.
