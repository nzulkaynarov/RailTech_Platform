«Настройки · Журнал · Выгрузки» — сделки в CSV для Excel: клиент, сумма, стадия и сроки, без контактов. Лиды и клиентов не выгружают: это персональные данные. Задайте фильтры и нажмите «Скачать»: файл получит имя с датой. Страницу ведёт администратор, у которого есть доступ к клиентам; директору она не показывается.
