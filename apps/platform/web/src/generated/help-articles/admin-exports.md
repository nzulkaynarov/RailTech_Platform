«Настройки · Журнал · Выгрузки» — лиды, клиенты и сделки в CSV для Excel. Задайте фильтры и нажмите «Скачать»: файл получит имя с датой. Выгружает администратор, у которого есть и доступ к самим данным (лиды или клиенты); директор видит страницу без права скачивать.
