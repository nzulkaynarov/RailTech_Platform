«Настройки · Компания · Нумерация» — схема номеров КП, договоров, счетов и актов. Новые номера пойдут по ней, выданные не меняются.

По умолчанию номера как `КП-2026/042`, `ДОГ-2026/104`, `СЧ-2026/142`, `АКТ-2026/058` (формат «Стандартный»). Номера, выданные раньше в виде `КП-2026-00042` или `CT-2026-00007`, остаются прежними, и поиск находит документ в любом из двух видов. Образец номера пересчитывается сразу, пока вы меняете схему.
