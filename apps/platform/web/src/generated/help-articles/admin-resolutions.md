«Настройки · Компания · Шаблоны резолюций» — общие шаблоны для входящих писем. Общий шаблон увидят все, кто готовит резолюции, — в форме резолюции, поле «Из шаблона».

В шаблоне: название, вид, текст, ответственный (сотрудник, «адресат письма» или «выбрать при резолюции»), соисполнители, «Ознакомить» и срок в днях (пусто — подсказка срока письма). Шаблон только заполняет форму: правка или удаление шаблона не меняют уже наложенные резолюции. Личные шаблоны директор и делопроизводитель сохраняют прямо из формы резолюции кнопкой «Сохранить как шаблон».

Директор видит страницу, менять общие шаблоны может только администратор.
