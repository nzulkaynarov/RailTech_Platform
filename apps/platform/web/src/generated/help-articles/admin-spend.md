«Настройки · Система · Расходы на ИИ» — сколько стоят модели ИИ:

- **Расходы бота** и **вся система** — по провайдерам и группам за период.
- **Бюджет моделей** — дневной лимит расходов на ИИ.
- **ИИ-помощник** в документах — «Заполнить из файла» при регистрации входящих: PDF с текстом помощник читает всегда, персональные данные система скрывает до отправки модели; сканы и фото пока не читает. Каждый вызов записывается в журнал без текстов писем.

Директор видит расходы, менять лимит может администратор.
