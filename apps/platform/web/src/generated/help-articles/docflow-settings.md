Раздел «Настройки → Документооборот» — правила для писем компании. Сейчас в нём «Справочники»: какие бывают виды входящих документов и способы получения писем. Из этих списков делопроизводитель выбирает в форме «Зарегистрировать входящее», по ним же работает отбор «Вид документа» во «Входящих письмах».

## Что можно сделать
- **Добавить значение** — название по-русски обязательно, по-узбекски и по-английски — по желанию (пусто — покажем русское). Новое значение сразу появляется в формах.
- **Изменить** — переименовать. Уже зарегистрированные письма покажут новое название.
- **Скрыть** — значение пропадает из форм, но остаётся у старых писем. «Вернуть» показывает его снова.
- **Удалить** — только то, чего нет ни у одного письма; использованное значение можно лишь скрыть.
- **Порядок** — стрелки «выше» и «ниже» в строке: в таком порядке значения стоят в формах.

## Виды входящих документов
У вида есть два своих поля:
- **Срочный** — письмо этого вида при регистрации сразу помечается «Срочно» (так устроено «Требование или уведомление ГНК»).
- **Срок исполнения, дней** — подсказка срока для резолюции директора, если в самом письме срока нет. Пусто — общее правило: срочное — 3 дня, обычное — 10.

Директор видит раздел, но менять справочники может только администратор.
