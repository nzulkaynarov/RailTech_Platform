«Настройки · Компания · Шаблоны документов» — вкладки:

- **Все шаблоны** — шаблоны всех разделов одной таблицей: документы и письма клиентам, резолюции директора, быстрые ответы бота. В колонке «Языки» видно, на каких языках шаблон есть (RU UZ EN, отсутствующий зачёркнут); метка «Образец» — шаблон платформы, «Выключен» — не используется. Фильтр «Вид шаблона» оставляет один вид. Название открывает шаблон там, где он правится. Видны только шаблоны разделов, доступных вам.
- **Документы** — шаблоны КП, договора, счёта и акта. Образец платформы можно открыть и скопировать к себе; свой шаблон — править с образцом.
- **Письма** — шаблоны писем клиентам. Включённый шаблон сразу заменяет стандартный для всех получателей.
- **Условия КП** — значения по умолчанию для новых КП: валюта, базис, НДС, наценка, сроки. Здесь же переключатель **«Напоминать клиентам о просроченных счетах»** (по умолчанию выключен): если включить, раз в сутки в 10:00 по Ташкенту по каждому счёту, у которого срок оплаты прошёл больше трёх дней назад, клиенту уходит одно напоминание — в колокольчике кабинета и письмом контакту проекта и приглашённым в кабинет. Пока переключатель выключен, клиенты напоминаний не получают; после включения напоминание по уже просроченным счетам уйдёт в ближайшие 10:00. Там же сроки: через сколько дней без подтверждения цена партнёра «устарела» (по умолчанию 30), за сколько дней до окончания она «истекает» (14) и как часто можно напоминать клиенту об акте (раз в 24 часа).
