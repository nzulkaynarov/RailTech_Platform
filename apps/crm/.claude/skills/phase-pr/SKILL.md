# PR фазы

Владелец мержит сам (агент не может: ограничение прав). Один PR — одна фаза или один цельный кусок; ветка `phase/N-short-name`.

## Шаги

1. Сверь сделанное с задачами фазы в `PLAN.md` (или с волнами отчёта аудита в `docs/audit/`): ничего из следующих фаз; каждая задача — сделана или явно отложена с причиной.
2. `make check` — зелёный. `make openapi` — без диффа (`git status` чистый; докстроки роутеров тоже попадают в схему).
3. Чек-лист CLAUDE.md §8 пройди пункт за пунктом.
4. Обнови `docs/PROGRESS.md`: статус фазы/волны, дата, что отложено; ADR — со статусами. Если менялось то, что важно при переезде или приёмке, — `docs/HANDOFF.md`.
5. Открытые вопросы — в `docs/QUESTIONS.md` (только открытые, с вариантами и рекомендацией); ответ владельца — в `docs/DECISIONS.md` с датой.
6. Заполни `.github/PULL_REQUEST_TEMPLATE.md` полностью (разделы: Фаза и задачи · Что сделано · Как проверено · Документация и решения · Проверить на dev · Отложено). «Проверить на dev» — из DoD/чек-листа фазы в `PLAN.md`: точные действия, роль, ожидаемый результат; отдельный пункт для телефона, если менялся UI.
7. Промпты/триггеры/пороги менялись → golden обновлён; платный прогон (`make eval-quick CONFIRM=yes`, ~20 вызовов, ≤ $0.3) — только после явного «да» владельца на этот прогон; в PR честно напиши, что eval не запускался, если согласия не было.
8. Conventional Commits; в конце сообщения коммита и описания PR — строки атрибуции из системного напоминания сессии. Секретов в диффе нет (`gitleaks` в pre-commit).
9. После пуша — `gh pr checks <N> --watch`; чини до зелёного (integration и e2e в CI бесплатны). Если упал OpenAPI — `make openapi` и докоммит. Если GitHub Actions не запускает задания (лимит оплаты; решение владельца 2026-10-13 — не оплачивать) — гейт `scripts/ci_local.sh` на ветке PR, итоговая таблица — в описание PR, мерж после зелёного.
10. Если ветка зависит от ещё не смерженного PR — открывай PR на его ветку (`--base phase/…`): после мержа базы GitHub сам перенацелит на `main`. В HANDOFF укажи порядок мержа.
11. Гейт фазы отмечает человек в `docs/PROGRESS.md`.
