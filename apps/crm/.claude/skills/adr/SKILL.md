# ADR

Когда: CLAUDE.md §5. Отклонение от SPEC — сначала предложение человеку (CLAUDE.md §2.2), ADR пишется после или вместе с вопросом в `docs/QUESTIONS.md`.

## Шаги

1. Номер: следующий свободный `NNNN` по `ls docs/adr/`. Номера 0004, 0007, 0008 зарезервированы `SPEC §16` — используй их только для соответствующих решений.
2. `cp docs/adr/0000-template.md docs/adr/NNNN-slug.md` (slug — латиница, kebab-case).
3. Заполни все разделы шаблона: контекст (со ссылками `SPEC §x.y`, `BUSINESS.md §x`), драйверы, ≥ 2 рассмотренных варианта с плюсами/минусами, решение, последствия (включая негативные), как проверяем.
4. Статус — `proposed`, дата — сегодня. `accepted` ставит человек (или ты после явного «принято» в обсуждении — с датой и ссылкой на обсуждение).
5. Ссылки:
   - строка в `docs/adr/README.md` (индекс);
   - если решение закрывает пункт `SPEC §16` — укажи номер ADR там;
   - если меняет SPEC — правка SPEC в том же PR (только после одобрения);
   - упоминание в `docs/PROGRESS.md` (раздел фазы).
6. Проверь: `make check` (ссылки в Markdown не ломают сборку, но prettier проверяет форматирование фронта — не docs).
