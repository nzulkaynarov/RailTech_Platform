# Страница CRM

Каркас Refine появляется в Фазе 4 (PLAN.md). Типы API — только сгенерированные (`frontend/src/api/`), ручные дубли запрещены. Компоненты без бизнес-логики — логика в хуках.

## Шаги

1. Страница и роли — по таблице `SPEC §10.1`; режим «Менеджер» скрывает админские разделы (`SPEC §10.2`).
2. Бэкенд-эндпоинт готов и в OpenAPI? Нет — сначала `api-endpoint`.
3. Ресурс Refine в `src/app/` (resources), страница в `src/pages/<name>/`, переиспользуемые части — `src/components/`.
4. Данные — через `dataProvider` (REST `/api/v1`); при необходимости новый метод провайдера с тестом.
5. Права — `accessControlProvider` по `GET /api/v1/me/permissions`: только скрытие/блокировка UI; 403 с бэка обрабатывается.
6. Тексты — i18n (ru/uz/en), без хардкода.
7. Адаптив до 390 px.
8. Тесты: Vitest для хуков/логики; Playwright smoke (вход → страница → ключевое действие).
9. `make check`; в PR — шаги «Проверить на dev» для каждой роли.
