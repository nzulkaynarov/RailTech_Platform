# Аудит скиллов агента (`.claude/skills/`) — 2026-10-12

Скиллы созданы в Фазе 0 по таблице CLAUDE.md §7, до появления большей части кода. За Фазы 1–9 и два аудита
(продуктовый 2026-10-09, дизайн 2026-10-11) изменились пути, команды и правила работы. Каждый шаг каждого
скилла сверен с репозиторием: файлы, цели `make`, тесты, ADR.
