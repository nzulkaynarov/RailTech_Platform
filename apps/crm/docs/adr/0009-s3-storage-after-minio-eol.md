# 0009. S3-хранилище после прекращения community-сборок MinIO

- Статус: proposed — **требует решения человека** (docs/QUESTIONS.md, Q-002)
- Дата: 2026-10-08
- Связано: SPEC §2 (Файлы), §3.2, §14; BUSINESS.md §8 («бесплатные open-source решения на собственном сервере»)

## Контекст и проблема

SPEC выбирает MinIO (`minio/minio`) для документов клиентов, исходников KB и вложений. Факты на 2026-10-08 (проверено при подготовке Фазы 0):

- образы `minio/minio` и `minio/mc` удалены с Docker Hub (по сторонним отчётам — 2026-09-11);
- README репозитория `minio/minio` начинается с «THIS REPOSITORY IS NO LONGER MAINTAINED» и отсылает к коммерческому AIStor;
- последний community-образ — `RELEASE.2025-09-07T16-13-09Z` (доступен в `quay.io/minio/minio`, по отчётам — с непропатченными уязвимостями; доступность quay.io из облачной среды агента не проверена — проверит CI);
- официальный compose Langfuse перешёл на `cgr.dev/chainguard/minio`.

Это отклонение от SPEC по факту внешнего мира, поэтому по CLAUDE.md §2.2 нужен выбор человека.

## Драйверы решения

- S3-совместимость (код работает по протоколу S3; presigned URL с TTL — Фаза 6).
- Поддерживаемость и обновления безопасности.
- Лицензия, позволяющая бесплатное self-hosted использование.
- Совместимость с Langfuse (`*_FORCE_PATH_STYLE`).

## Рассмотренные варианты

1. **Временно** — последний community-образ MinIO из quay.io (замороженный), переход позже.
2. RustFS (`rustfs/rustfs`, Apache-2.0, S3-совместимый, позиционируется как замена MinIO; последний тег 1.0.1).
3. SeaweedFS (`chrislusf/seaweedfs`, Apache-2.0, зрелый, S3-gateway).
4. Garage (`dxflrs/garage`, AGPL-3.0, лёгкий, для небольших инсталляций).
5. Chainguard MinIO (`cgr.dev/chainguard/minio`) — бесплатно обычно только тег `latest` (не проверено).

## Решение (предлагаемое)

В Фазе 0 — вариант 1 как временная мера: образ задаётся переменной `MINIO_IMAGE` (по умолчанию `quay.io/minio/minio:RELEASE.2025-09-07T16-13-09Z`), приложение обращается к хранилищу только по S3-протоколу и health-эндпоинту. **До Фазы 1** (первые реальные файлы) выбрать постоянную замену; рекомендация агента — **RustFS** или **SeaweedFS** после короткого spike в CI (S3 API: put/get/presigned, healthcheck, совместимость с Langfuse). Решение фиксируется в этом ADR, SPEC §2/§3.2 обновляются.

### Последствия

- Хорошо: Фаза 0 не блокируется; замена — конфигурационная.
- Плохо: замороженный образ не получает исправлений безопасности — недопустим для prod; health-эндпоинт `/minio/health/live` специфичен для MinIO и меняется вместе с выбором.

### Как проверяем

CI integration-job поднимает выбранный образ и прогоняет тесты хранилища. Prod (Фаза 8) — только с поддерживаемым образом.
