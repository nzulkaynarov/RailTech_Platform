# Вопросы к владельцу

Здесь только вопросы, на которые нужен ответ (CLAUDE.md §2.12). Формат: контекст → варианты →
рекомендация. После ответа вопрос переезжает в `docs/DECISIONS.md`.

### Q-021. Когда создаётся открытая сделка

Контекст: полный аудит 2026-10-12 (`docs/audit/2026-10-12-full-audit.md`). Ни один штатный путь не создаёт открытую сделку → отказы не попадают в аналитику. Q-013 говорит «при квалификации», ADR-0019 — «вручную или при закрытии».
Рекомендация: автоматически при стадии «Квалифицирован» и при «Новая сделка»; отказ без сделки создаёт проигранную.

### Q-022. Язык при первом контакте

Контекст: у Telegram нет узбекского интерфейса — узбекоязычные получают согласие на русском.
Рекомендация: кнопки «Oʻzbekcha / Русский / English» первым сообщением, затем согласие на выбранном языке.

### Q-023. Контакты компании в боте

Контекст: на «дайте номер менеджера» бот отвечает «номера у меня нет».
Рекомендация: телефон, сайт, адрес в «Настройки → Компания»; бот отвечает детерминированно.
