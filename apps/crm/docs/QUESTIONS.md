# Вопросы к человеку

Агент фиксирует здесь вопросы, чтобы на них можно было ответить пакетом (CLAUDE.md §2.12).
Формат: контекст → варианты → рекомендация. Ответ — прямо под вопросом; закрытые переносятся вниз.

## Открытые

### Q-001. Имя ветки фазы

Контекст: CLAUDE.md §2.9 и §10.11 требуют ветку `phase/0-foundation`. Облачная среда, в которой работает агент, назначила рабочую ветку `claude/epic-galileo-vy585i` и запрещает пушить в другие без явного разрешения.
Варианты: (а) оставить PR из назначенной ветки — нарушение только в имени; (б) разрешить агенту пушить в `phase/N-*` (явно в сообщении).
Рекомендация: (б) для следующих фаз; Фаза 0 — из назначенной ветки.

### Q-002. Замена MinIO (ADR-0009) — **блокирует Фазу 1**

Контекст: образы `minio/minio` удалены с Docker Hub (2026-09), репозиторий не поддерживается. Сейчас стоит замороженный `quay.io/minio/minio:RELEASE.2025-09-07T16-13-09Z` (переопределяется `MINIO_IMAGE`).
Варианты: RustFS (Apache-2.0) · SeaweedFS (Apache-2.0, зрелый) · Garage (AGPL-3.0) · оставить замороженный MinIO (не для prod).
Рекомендация: разрешить spike RustFS vs SeaweedFS в начале Фазы 1 (S3 put/get/presigned + Langfuse), затем обновить SPEC §2/§3.2.

### Q-003. Langfuse v4: Redis и ClickHouse, путь `/langfuse`

Контекст: актуальный self-hosted Langfuse — v4 (v3 получает патчи безопасности до января 2027). Ему нужны ClickHouse и Redis (+ S3). SPEC §2 говорит «не используем Redis»; SPEC §3.2 допускает «зависимости по официальному compose». Кроме того, Langfuse не поддерживает работу под путём `/langfuse` без собственной сборки образа (SPEC §3.2, §11 предполагают `/langfuse` за Caddy).
Сделано: профиль `observability` с Langfuse 4.55.0, ClickHouse, Redis; БД `langfuse` в нашем Postgres, бакет `langfuse` в нашем S3. Redis используется только Langfuse.
Нужно решение: (1) подтвердить, что запрет Redis относится к приложению, а не к внутренним зависимостям Langfuse; (2) для prod (Фаза 8) — поддомен `langfuse.<домен>` с IP allow-list вместо пути `/langfuse`.
Рекомендация: да / поддомен. Python SDK Langfuse тогда ≥ 4.7 (Фаза 2).

### Q-004. Где лежат промпты

Контекст: SPEC §4 показывает и `backend/prompts/`, и `app/agents/{dialog,qualifier}/prompts/`; CLAUDE.md §4 — «промпты только в `backend/prompts/*.md`».
Рекомендация: убрать `prompts/` из `agents/*` в SPEC §4. Сейчас создан только `backend/prompts/`.
